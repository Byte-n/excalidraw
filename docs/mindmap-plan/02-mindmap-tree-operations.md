## 用户可见目标

用户可以通过键盘和菜单整理树结构，折叠分支，安全删除节点，提升层级，并将一级分支拆成独立导图。

## 实施任务

### 导航与折叠

- [ ] 单选且非文字编辑时，`ArrowUp` / `ArrowDown` 按逻辑顺序切换同级，`ArrowLeft` 选父节点，`ArrowRight` 选第一个可见子节点。
- [ ] 导航边界不跳入其他导图；折叠节点的隐藏后代不作为普通导航目标。
- [ ] 节点显示折叠/展开控制点，支持 `Space`；叶子节点不产生无意义折叠修改。
- [ ] 折叠后保留后代、文本和 edge 数据，只重新布局可见节点，清理不再可见的选择状态。
- [ ] 隐藏后代不参与命中与普通框选；展开恢复完整分支。

### 删除与换根

- [x] `Delete` 或平台对应的删除键默认删除节点及完整子树，包括折叠后代、绑定文字与相关 edge，不弹窗；根节点则删除整张脑图。
- [x] `Shift+Delete` 删除当前节点并保留后代，以下子节点数量均按直属子节点计算。
- [x] 根节点没有子节点时直接删除；只有一个子节点时自动由它作为新根；多个子节点时弹窗指定新根，其余分支按原顺序追加到新根已有子节点之后。
- [x] 普通节点没有子节点时直接删除；只有一个子节点时由它接替原位置，挂到原父节点下，不弹窗。
- [x] 普通节点有多个子节点时弹窗选择：所有子节点依次放入原父节点下、占据原节点的位置；或指定一个子节点接替原节点，其余分支按原顺序追加到接替节点已有子节点之后。
- [x] 普通节点的接替操作不拆图：保持原父节点、原同级位置和 `graphId`，保留全部分支内部关系、样式和绑定文字。
- [x] 弹窗打开、取消或非法接替目标不修改场景；删除后选择有效节点或清除选中，确认后的结构及自动布局仅产生一次历史。

### 提升与拆图

- [ ] 深层节点执行 `Shift+Tab` 后成为父节点的同级，插在原父节点之后，后代关系保持不变。
- [ ] 一级节点执行 `Shift+Tab` 后连同完整子树拆成新导图：新根的 `parentId`、`order` 置空，整棵子树使用新 `graphId`，移除旧入边。
- [ ] 拆图同时更新原图与新图，保留绑定文本及已有样式；一次撤销恢复原关系。
- [ ] 根节点执行提升时不产生变化。
- [x] 创建、删除完整子树、删除节点并保留子节点、折叠和提升均提供 Mindmap 上下文菜单入口。
