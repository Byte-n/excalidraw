## 用户可见目标

用户能在样式面板中调整节点与连接线外观，切换四种布局方向，并在复制、换根、拆图和重开文件后保留配置。

## 实施任务

### 节点与连接线样式

- [x] 提供矩形、椭圆、菱形、胶囊四种节点形状。
- [x] 接入填充色、边框色、边框粗细、字体、字号、文字对齐、圆角和透明度等适用样式。
- [x] 字体、字号、形状等影响文本空间的修改重新测量尺寸并布局；纯颜色修改不改变结构。
- [x] 提供 edge 颜色、粗细、线型及 `orthogonal` / `curved` 路由。
- [x] 通过节点的入边设置与整图连接线设置暴露样式，不开放 edge 端点自由编辑。
- [x] 重新布局及 edge 修复保留用户样式，不重复重置为默认外观。

### 多方向布局与交互

- [x] 支持左到右、右到左、上到下、下到上，默认延续左到右。
- [x] 使用稳定的层级间距和兄弟间距，四方向布局不提供额外间距配置。
- [x] 布局保持根节点锚点，按逻辑 `order` 安排兄弟及子树，按形状边界计算连接线连接位置。
- [x] 四种方向下同步调整添加控制点、折叠控制点、同级插入区域和拖拽预览。
- [x] 键盘仍按“上下同级、左父、右子”的逻辑语义导航，不随视觉方向改义。
- [x] 普通结构操作的自动布局归属于原操作；本期不单独提供手动重新布局命令。

### 配置持久化与兼容

- [x] 在根节点的正式类型字段中保存图级方向及必要默认样式，不使用 `customData` 或仅保存在本地 AppState。
- [x] 旧文件缺省字段恢复为现有布局默认值，重复恢复结果稳定。
- [x] 换根、拆图、复制与粘贴为新图时正确继承配置；普通粘贴保持独立副本语义，不并入已有导图。
- [x] 保存、导出、撤销重做覆盖全部新增设置。

## 界面验收

使用含不同尺寸、四种节点形状和折叠分支的多层导图，每种方向均执行一次编辑与挂接。

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| P05-01 | 依次切换四种方向 | 根锚点稳定，兄弟顺序可辨，子树不重叠，连接线方向正确 |
| P05-02 | 调整字体、字号、形状与长文本 | 文本容纳正确，节点尺寸与连接线同步更新 |
| P05-03 | 分别修改节点入边与整图连接线样式 | 作用范围明确，路由正确，样式不被重置 |
| P05-04 | 修改字体、字号或形状后撤销、重做 | 节点尺寸、连接线和样式作为一次语义操作完整回退和恢复 |
| P05-05 | 在四种方向下添加、折叠、拖拽挂接及同级排序 | 控制点和插入指示器与实际结果一致 |
| P05-06 | 复制整图、拆分一级分支、删除根并指定新根 | 各路径正确继承或应用布局配置 |
| P05-07 | 保存重开新配置场景，再打开旧版默认场景 | 新设置保留，旧场景兼容，PNG/SVG 与可见状态一致 |
| P05-08 | 在非左到右布局中使用方向键 | 导航仍遵循父子/同级逻辑，不意外变成坐标移动 |
| P05-09 | 从文件菜单打开 [P05 样例](samples/p05-mindmap.excalidraw)，检查初始状态后依次修改方向、形状、节点样式和 edge 样式 | 样例可直接打开；四种形状、折叠分支、两张导图和普通图形均可识别，样式面板入口明确 |
| P05-10 | 修改配置后保存 JSON，清空画布并重新打开；再打开旧版默认样例 | 新字段、绑定文字、折叠状态和布局方向保留；缺省字段使用稳定默认值 |
| P05-11 | 折叠分支后分别导出 PNG 和 SVG，再展开后重复导出 | 导出只包含当前可见节点、文字和 edge，导出边界随可见状态变化 |
| P05-12 | 取消拖拽、放置到非法目标、取消样式输入，并在旁边移动普通矩形和 Arrow | 取消和非法操作不产生场景或历史变化；普通图形保持原生行为 |
