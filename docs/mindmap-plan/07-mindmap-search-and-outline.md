## 实施任务

### 搜索与定位

- [x] 搜索节点绑定文字，覆盖折叠子树，不把同一绑定文本重复呈现为多个结果。
- [x] 搜索结果显示所属导图和层级路径，区分不同图内的同名节点。
- [x] 输入查询和切换结果高亮不修改场景结构。
- [x] 点击隐藏节点结果时展开必要祖先、选中节点并将其移入视口；实际折叠状态修改归入一次历史。
- [x] 节点被删除、重命名、移动或收到远端变化后更新结果，失效结果不能跳到错误节点。

### 大纲视图与编辑

- [x] 提供 Mindmap 大纲侧栏，按照图索引和 `order` 展示层级，不依据画布坐标排序。
- [x] 画布与大纲双向同步选中、标题和折叠状态。
- [x] 支持大纲内重命名、添加子节点/同级节点、删除、删除子树、折叠、提升及拆图。
- [x] 支持大纲拖拽挂接和兄弟排序，复用已有目标合法性与提交规则。
- [x] 大纲不维护第二份可独立修改的树；编辑、历史和协作都走统一命令。
- [x] 将只读层级呈现与编辑命令解耦，供后续导入和 AI 预览复用，不把预览树写入场景。

### 审查准备与操作

- 预览地址：`http://127.0.0.1:5173/`。通过“文件 → 打开”加载 [P07 样例](samples/p07-mindmap.excalidraw)。样例含普通矩形和 Arrow、两张导图、折叠的“调研”、两张图中的“用户访谈”。每项破坏性操作前重新加载样例。
- 搜索入口：`Ctrl/Cmd+F`；大纲入口：打开右侧默认侧栏后点击导图图标标签。大纲节点右侧操作菜单提供重命名、添加子节点/同级节点、提升或拆图、保留后代删除和删除整个分支。
- P07-01 至 P07-03：搜索“用户访谈”，确认折叠分支的结果与另一张图的同名结果各出现一次、图号和路径不同；输入查询时“调研”保持折叠。点击隐藏结果后确认定位与选中，撤销一次恢复折叠。
- P07-04：在大纲中重命名“调研”，按 Escape 取消一次，再按 Enter 提交；继续添加子节点和同级节点、删除分支、保留后代删除、提升一级节点。每次检查画布与大纲同步及单次撤销；多子节点的保留删除弹窗按“取消”应无变化。
- P07-05：把大纲节点拖到另一节点行中间以挂接，拖到行上沿或下沿以同级排序；再在画布拖回。把父节点拖到其后代上、或跨图拖动，应被拒绝且不增加历史。
- P07-06：沿用 P06 的真实协作房间，在 A 端保留搜索结果和大纲，B 端重命名、移动、删除对应节点；A 端结果、路径和大纲应更新，失效项不能跳到别的节点。
- P07-07：保存 JSON、清空并重新打开，再打开大纲；图结构、顺序、文字和折叠状态应与保存时一致。
