恢复实施时仍需结合当时的版本状态确认 P08 验收结果和其他前置条件。

## 用户可见目标

用户可以保存并重复创建自己的分支模板作为独立导图，应用节点样式和整图主题；模板创建直接写入画布，主题仍支持外观预览。

## 实施任务

### 节点与子树模板

- [ ] 提供内置节点样式模板与可辨认的缩略展示。
- [ ] 将选中子树保存为命名模板，包含完整结构、文字、样式、折叠数据和必要布局配置。
- [ ] 复用既有本地持久化或素材库机制，刷新后仍能访问保存的模板。
- [ ] 模板面板直接创建独立的新导图，重新生成节点、文本、edge 身份和新的 `graphId`。
- [ ] 创建结果与模板及原图完全独立，不保持会被共同修改的元素引用。
- [ ] 模板创建遵守独立导图的布局规则，复用 P04、P05 的配置继承和原子提交。

### 主题预览与应用

- [ ] 提供内置导图主题，覆盖节点和 edge 的协调样式。
- [ ] 内置主题预设作为版本化代码数据随应用发布，不写入模板存储或场景；应用主题时将解析后的节点/edge 样式写入正式元素，保存重开后保持已应用外观。
- [ ] 明确作用范围：整图或选中子树；节点样式模板的应用范围同样可见。
- [ ] 预览使用独立渲染结果，不提前修改正式元素、历史和协作状态。
- [ ] 确认后仅应用样式及必要尺寸布局，不改变文字、父子关系或同级顺序。
- [ ] 取消恢复原外观；确认应用可一次撤销；预览期间选择或目标失效时清理预览。

## 界面验收

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| P09-01 | 将含折叠后代的复杂分支保存为命名模板，刷新应用 | 模板仍可找到，直接创建后结构信息正确 |
| P09-02 | 在已有场景中连续创建两份模板导图 | 两份结果结构、文字、样式完整且身份独立，已有导图不变 |
| P09-03 | 修改一份模板导图，再次创建同一模板 | 原图、已保存模板与另一份副本不受影响 |
| P09-04 | 对节点应用样式模板，对子树和整图分别预览主题 | 范围明确，只有目标范围发生预览变化 |
| P09-05 | 取消一次主题预览，再确认另一主题并撤销 | 取消完全恢复；确认可一次撤销，不修改结构与文字 |
| P09-06 | 在协作中预览并应用主题、创建模板导图 | 另一端看不到主题预览；模板创建后收到完整的新导图结果 |
| P09-07 | 保存应用主题后的场景并重开 | 外观保留，分支关系和折叠数据不丢失 |

## 自动化与回归

- [ ] 模板持久化、完整折叠子树收集、重复创建身份唯一性与引用隔离测试。
- [ ] 模板创建为独立新图的配置继承、身份隔离和原子历史测试。
- [ ] 主题作用范围、取消清理、样式尺寸变化与结构不变测试。
- [ ] 验证预览不进入协作载荷，主题应用和模板新图创建可正确同步。
- [ ] 回归复制、导入、样式面板和保存恢复。
