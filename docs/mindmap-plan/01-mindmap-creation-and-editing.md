# 第 01 期：创建、编辑与保存

- 期次：P01。
- 状态：已实现，待用户界面审查。
- 里程碑：核心 MVP 的第一个可用闭环。
- 总体约束与完成门槛：[分期总览](00-mindmap-overview.md)。

## 依赖关系

- **前置验收**：已完成的 Mindmap 基础设施，无前置功能期。
- **主要能力依赖**：正式 node/edge 类型、图索引、结构校验与修复、左到右布局、绑定文本、场景恢复及渲染导出基础。
- **外部依赖**：无，使用仓库现有应用进行本地界面验收。
- **后续承接**：[P02 树操作与键盘导航](02-mindmap-tree-operations.md)；本期建立的提交链路由所有后续功能复用。

## 用户可见目标

用户不需要控制台或手工构造 JSON，就能从空白画布创建一张多层导图，编辑文字，撤销重做，保存并重新打开。

## 实施任务

### 创建入口与节点关系

- [x] 在工具栏的更多工具中增加“思维导图”入口及对应状态提示。
- [x] 点击空白处创建根节点、独立绑定文本，并立即进入文本编辑。
- [x] 悬停节点显示添加子节点控制点；点击后创建子节点并进入文字编辑。
- [x] 单选节点且未编辑文字时，`Tab` 创建子节点，`Enter` 在当前节点之后创建同级节点；根节点按 `Enter` 创建子节点。
- [x] 为新节点分配合法的 `parentId`、`order` 和 edge；根节点和普通节点具有可辨认的默认外观。

### 编辑与自动布局

- [x] 双击节点进入现有文本编辑器，复用自动换行、字体测量、中文输入和多行文字能力。
- [x] 文字编辑及 IME 组合期间不拦截文本编辑器的默认按键，避免误创建节点。
- [x] 文字编辑完成时同步节点尺寸、绑定文本位置和布局，不为每次输入额外提交完整布局。
- [x] 创建和文字修改通过统一提交链路更新场景、版本与历史；布局不额外生成第二条记录。

### 保存与安全边界

- [x] 通过现有文件菜单保存、打开 JSON 场景，保留所有正式字段与绑定关系。
- [x] 普通矩形、Arrow 和具有宿主 `customData` 的元素不参与 Mindmap 结构。
- [x] 对本期尚未支持的 Mindmap 删除、拖拽、复制、变换和协作修改入口做保护，普通图形不受限制。
- [x] 增加中文/英文界面文案、控件标签和键盘提示。

## 界面验收

先从空白画布开始，每次结构快捷键操作前结束文字编辑并单选节点。

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| P01-01 | 选择“思维导图”，点击画布并输入“产品规划” | 出现根节点并可直接输入文字 |
| P01-02 | 使用根节点的添加按钮与 `Enter`、`Tab`，建立“调研、方案、上线”及其子节点 | 父子关系正确，兄弟顺序稳定，连接线自动生成 |
| P01-03 | 双击“用户访谈”，输入中文、多行长文本 | 输入法和换行正常；结束编辑后节点、文字和连接线同步调整，无重叠 |
| P01-04 | 分别对创建及已存在节点的文字修改执行撤销、重做 | 每个已提交语义操作完整回退和恢复，没有只撤销布局的中间状态 |
| P01-05 | 保存文件，清空后通过文件菜单重新打开 | 文字、结构、样式与布局一致，无缺失绑定文本 |
| P01-06 | 在导图旁绘制普通矩形和 Arrow，靠近节点放置 | 保持普通图形行为，不自动挂接 |
| P01-07 | 在文本编辑时按方向键、空格、`Enter` 和 `Tab` | 保留文本编辑器既有行为，不触发结构命令 |

## 本期验收材料

- 预览地址：`http://localhost:3001/`。选择“更多工具 → 思维导图”；移动端入口位于同一工具菜单。
- 样例文件：[p01-mindmap.excalidraw](samples/p01-mindmap.excalidraw)。通过“文件 → 打开”加载，包含两张导图、折叠的“调研”后代、普通矩形、普通 Arrow 和 `customData`。
- 空白画布验收：选择思维导图后点击空白处，输入“产品规划”；结束编辑后单选节点，使用悬停添加按钮、`Tab` 和 `Enter` 创建分支。
- 文本验收：双击节点输入中文和多行文字，按 `Escape` 结束；再执行撤销和重做，确认节点、绑定文本、连接线和布局一起变化。
- 安全边界：对导图节点尝试删除、复制、剪切、拖拽或缩放会保持结构并显示暂不支持提示；普通矩形和 Arrow 仍按原有工具行为工作。

自动化命令：`yarn test:app run packages/excalidraw/tests/mindmapCreation.test.tsx`、`yarn test:typecheck`、`yarn test:code`、`yarn build:excalidraw`。

当前限制：P01 不包含删除、拖拽挂接、复制、折叠命令、样式面板或协作结构修改，这些入口按计划保留保护提示并留给后续期次。
