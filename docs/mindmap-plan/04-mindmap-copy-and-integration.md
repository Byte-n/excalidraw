## 用户可见目标

用户可以安全复用整图和子树，使用既有复制、链接、锁定与导出功能，并在明确解除结构后转换为普通图形。

## 实施任务

### 复制、剪切与粘贴

- [x] 按语义收集整图或子树的全部节点、绑定文本和内部 edge，包括折叠后代；不复制子树原父节点的入边关系。
- [x] 整图或子树粘贴为独立副本时生成新节点 ID 和新 `graphId`，修复所有内部引用。
- [x] 接入原生复制、剪切、粘贴和重复复制快捷键；文字编辑期间保留文字剪贴板行为。
- [x] 剪切在剪贴板写入成功后再删除完整所选子树，防止写入失败时丢失内容；每次场景修改保持原子历史。
- [x] 接入 `Alt/Option` 子树复制拖拽，复用 P03 预览；取消不生成正式副本。

### 原生操作边界

- [x] 适配节点链接、锁定与解锁；按整张 Mindmap 检查实际影响的元素，不能通过移动父节点或混选绕过锁定。
- [x] 节点转普通图形前解除结构关系；普通节点的剩余子节点按 P02 规则提升。
- [x] 支持整图转换，内部 edge 转为普通线。
- [x] 转换保留对应文字、样式和可保留的通用属性，清理不再适用的 Mindmap 关系字段。
- [x] 继续阻止 edge 独立端点编辑，以及绕过自动布局的节点自由旋转、缩放等原生变换。
- [x] 对原生菜单、快捷键和重复复制入口使用一致的守卫与语义，避免只有专用按钮正确。

### 导出与往返

- [x] PNG、SVG 导出当前可见布局，正确处理节点、文字、edge 和选中范围。
- [x] JSON 保存完整子树、折叠状态及正式字段，重新打开后仍可继续编辑。
- [x] 复制后修改副本不得影响原图；普通图形复制及宿主扩展字段保持兼容。
