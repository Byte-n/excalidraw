## 状态

- `提议`：正在讨论，尚未约束实施。
- `已采纳`：当前有效，实施必须遵守。
- `已放弃`：评估后不采用，保留原因。
- `已取代`：被更新的 ADR 取代；正文保留，只更新状态与取代链接。

新增 ADR 时，在索引中登记编号、标题、状态、日期、关联 spec 和取代关系；索引与 ADR 同一提交更新。
