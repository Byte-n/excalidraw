白板画布样式设计稿

设计方向：精确矢量 + 宿主一致。元素改为干净的矢量线条与浅色填充，去掉手绘抖动；选中、选区与右键菜单统一使用文档平台的主色 #1677FF 和系统字体，让白板像平台的一部分，而不是嵌入的第三方工具。

总览

一个典型的流程白板：「需求评审」被选中并打开右键菜单，「上线」处于悬停状态，右下角正在框选两个元素。

前后对比

左侧为当前 Excalidraw 默认风格的示意（手绘抖动、手写字体、紫色选中框），右侧为新风格。

选择与选区状态

同一个元素在各交互状态下的表现。选中类反馈只用主色一种颜色，用实线、虚线和透明度区分层级。

旋转

沿用当前交互：旋转手柄在右上角外侧，从任意位置按下手柄都按拖拽起点的角度增量旋转；拖动时手柄隐藏，改由跟随角度旋转的光标指示。

右键菜单

紧凑的 32px 行高，按操作类型分组；快捷键右对齐并弱化，子菜单向右展开，删除放在最后并使用危险色。

元素调色板

新建元素默认使用「墨色」描边、无填充。调色板刻意避开主色蓝，确保选中反馈永远不会与内容颜色混淆。
