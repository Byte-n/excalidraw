表格

表格从「一组网格线」改为平台文档表格的样式：白底、圆角外框、浅色网格，首行作为表头；选择与编辑反馈全部使用主色，行列把手与插入点只在表格被选中或悬停结构区时出现。

交互状态

表格标题

标题是表格上方的独立文本，与 Frame 标题同风格（12px/500）；左侧六点把手用于拖动整个表格。无标题时悬停显示半透明占位，点击进入编辑。

行列把手与插入点

把手为 6px 圆角条、距表格 6px，内嵌 2×3 点阵暗示可拖动；插入点位于每个行列边界外侧 18px 处。全部命中区桌面 24px / 触屏 44px。
