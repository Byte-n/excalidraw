白板选中工具栏设计稿

选中元素后的属性工具栏（样式面板）：统一桌面 full 面板、平板 compact 图标岛、手机底部条三种容器的 DOM 结构与控件样式，覆盖普通图形、多选、 文本、线性元素、图片、Frame / MagicFrame、便签、表格、思维导图（整树 / 节点 / 连线）、嵌入元素、复合形状、工具配置（无选中）、锁定与只读等全部场景， 并含元素画布悬浮按钮。令牌与「白板画布样式设计稿」 及复合元素系列一致。

Frame 表格 思维导图 便签 连接线与箭头

设计目标与统一原则

现状三种容器（full 面板 / compact 图标岛 / 手机底部条）各自排版， 思维导图专属面板还混用原生 input[type=color] 与数字输入框，分组顺序和控件样式随场景漂移。本次以「场景矩阵」为唯一事实源， 把分组、控件、弹层收敛为一套规范。

一处定义，三端同源

分组集合与顺序以场景矩阵为唯一事实源；浮动工具栏（桌面 / 平板）与底部条（手机）只是同一组分组的两种容器，不各自增删。

控件统一

颜色一律色板（禁用原生 color input），数值一律滑杆 + 输入框，枚举一律分段选择器，动作一律图标按钮；同属性跨场景同一控件。

令牌统一

颜色、阴影、圆角全部走主题令牌（主色 #1677FF / 暗色 #4096FF），禁止散落字面色值；亮暗双主题自动适配。

弹层统一

二级界面共用弹层容器（圆角 10、内边距 8、统一阴影与箭头）；手机端一律改为底部 sheet，不再右侧弹出。

容器结构与 DOM 规范

桌面与平板统一为「浮动工具栏」：横排胶囊，跟随选区定位（上方居中，间距 12px，空间不足翻到下方）；高频颜色直接外露，其余每组一个图标、点击弹出属性弹层。手机为底部条 + 底部 sheet。分组统一为 fieldset > legend + 控件行（现状 h3 与 legend 混用，本次收敛）；弹层 / sheet 内的分组集合与顺序 = 场景矩阵，三端不各自增删。

场景设计稿（桌面 / 平板：浮动工具栏）

每个场景：左侧画布展示浮动工具栏相对选区的定位与外露项；中间列为该场景的 全部分组内容（由声明式序列 data-pp 渲染）——桌面 / 平板从浮动栏弹层打开，手机从底部 sheet 打开，三者内容完全一致；右侧为要点。便签、表格、思维导图的画布选中态详见各自设计稿。

工具配置（无选中）新增

激活绘制工具、尚未选中元素
  • 浮动栏固定于视口顶部居中（主工具条下方 12px，不跟随元素），配置下一个元素的默认样式
  • 分组序列 = 该工具产出元素的对应场景，图示为矩形工具
  • 桶填充变体 bg（无透明）|fill|opa；切回选择 / 套索 / 橡皮 / 抓手 / 激光笔即隐藏
  • 手机端以底部条呈现同一序列

单个普通图形

矩形 / 椭圆 / 菱形
  • 分组序列 stroke|bg|fill|width|style|round|opa|layers|actions:link
  • 椭圆没有「边角」组，其余相同
  • 填充样式 = 斜线 / 网格 / 纯色；无填充 = 背景选「透明」
  • 单选时操作组追加「链接」按钮（弹层：编辑 / 访问两态）

多个普通图形（同类多选）

≥2 个图形
  • 属性不一致的分组显示「多值」虚线色板（@mix 状态，新增）
  • 追加「对齐」组；超过 2 个元素再追加「分布」组
  • 操作组追加「成组」

混合多选（图形 + 文本 + 图片）

跨类型并集
  • 分组取成员能力并集：文本带来字体组，图片不贡献颜色组
  • 图片无描边，故「描边宽度 / 样式」不出现
  • 应用到多值分组时作用于所有具备该能力的成员

文本

独立文本与标签
  • 「颜色」即描边色，标签改写为「颜色」
  • 容器绑定文本追加「垂直对齐」组（上 / 中 / 下）
  • 编辑中浮动栏保持可见，改动实时作用于文本

箭头 / 连接线

普通箭头与绑定连接线共用
  • 「箭头类型」= 直线 / 曲线 / 折线；「端点」打开端点库
  • 操作组含「编辑节点」（elbow 除外）
  • 绑定开关保持在右键菜单，不进面板
  • 线条（非箭头）无类型 / 端点组；「边角」组含「闭合多边形」开关，闭合后的线条支持背景颜色与填充样式

线条 · 编辑节点模式新增

编辑节点
进入「编辑节点」后，属性浮动栏整体替换为模式条：模式名 + 「完成」主按钮（Enter / Esc 同效）；属性分组在此模式下不可用，退出后回到正常浮动栏。手机端底部条同样替换。
逐点编辑线条 / 箭头（elbow 除外）
  • 顶点 = 实心锚点，选中点主色填充；中点 = 6px 半透明加点手柄（画布规格详见连接线设计稿）
  • 底部提示条沿用 HintViewer 现状文案（选点 / 加点 / 删点 / 拖点）
  • 「闭合多边形」开关在属性面板边角组（场景矩阵⁷），模式条不重复提供

自由绘制

画笔笔迹
  • 闭合笔迹支持背景颜色与填充样式；无描边样式
  • 「压感」= 固定 / 压感；其余分组与图形一致

图片

位图与贴纸
  • 无描边 / 背景 / 填充；保留「边角」「透明度」
  • 操作组含「裁剪」，进入裁剪模式后面板让位给裁剪确认条

图片 · 裁剪模式新增

裁剪图片
属性浮动栏整体替换为确认条：模式名 + 取消（✕ / Esc 还原到进入时状态）+ 应用（主按钮 / Enter / 双击画布）。定位同浮动栏锚定规则；拖动裁剪框时确认条不隐藏。手机端底部条同样替换。
单选图片 → 操作组「裁剪」
  • 画布规格：保留区正常渲染，裁掉区 35% 透明，四角裁剪手柄
  • 底部提示条沿用 HintViewer；确认条动效同浮动栏（120ms）
  • Stats 面板此时 W / H 显示未裁剪原始尺寸（见「属性统计面板」）

Frame

Frame 本体
  • 无描边 / 背景（样式固定，见 Frame 设计稿）
  • 浮动栏「重命名」按钮聚焦画布标题输入框（双击标题同效）
  • 「更多」内含导出 Frame 为图片
  • MagicFrame 分组同 Frame；选中时元素边缘外侧悬浮「转换为代码」画布按钮（tb-canvasbtn，拖动 / 旋转 / 菜单打开时隐藏）

便签

纸片便签
  • 「文字颜色」走墨色板；「纸色」为六色专用纸色板
  • 无描边宽度 / 样式 / 填充（纸片无描边）
  • 字体 / 字号 / 文字对齐经便签文字（绑定文本）生效，控件与文本场景一致
  • 日期页脚不可编辑，不在面板出现

表格 · 选中整体

表格整体（P06 风格）
  • 描边系分组改名「边框」，「边框颜色」与「网格线颜色」为两个独立色板（互不影响，透明边框不影响网格）
  • 「表头」为复选项；「标题对齐」作用于表格标题
  • 透明度与图形一致（滑杆 0–100）
  • 行 / 列选中时面板仅保留边框色 + 背景色两组（作用于该行 / 列）

表格 · 单元格选区

进入单元格 / 行列选区后，浮动栏与弹层内容整体替换
  • 「选区模式」切换单元格 / 整行 / 整列
  • 「合并」组：合并选中、拆分；不可用时禁用
  • 样式只作用于选区：单元格背景、文字颜色

思维导图 · 整树（选中根节点）

选中根节点 = 操作整棵树
  • 「布局方向」四选一：向右 / 向左 / 向下 / 向上
  • 「默认连线」= 颜色 / 宽度 / 线型 / 路径（曲线 / 正交）四子组，作用于整树未单独设置的分支
  • 「更多」含一键整理布局、展开 / 折叠全部

思维导图 · 单个节点

分支 / 叶子节点
  • 「节点形状」= 自动 / 矩形 / 椭圆 / 菱形 / 胶囊
  • 「入边样式」= 跟随分支 / 实线 / 虚线 / 点线
  • 通用描边 / 背景 / 填充 / 描边宽度 / 描边样式 / 边角 / 透明度照常出现在弹层；字体 / 字号 / 文字对齐经节点文本生效；图层进「更多」
  • 手机端此浮动栏替换为底部动作条（见「响应式」）

思维导图 · 连线

选中一条分支连线
  • 统一 弃用原生 color / number 输入；「连线样式」= 颜色 / 宽度 / 线型 / 路径（曲线 / 正交）四子组，色板 + 分段选择器

  • 开放形态（分栏 / 列表等）无背景与填充分组

锁定与只读

已锁定
锁定场景不显示属性分组，也不弹任何弹层；浮动栏内联 「已锁定 + 解锁」，解锁后立即切换为正常浮动栏。
锁定元素统一
  • 全锁定选区：浮动栏 = 锁定图标 + 「已锁定」+ 解锁主按钮（现状面板无特判、解锁入口只在画布角标）

  • 只读模式：不显示浮动栏，画布顶部显示「只读模式」胶囊
