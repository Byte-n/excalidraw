# 第三期：样式、文本与高级变换

- 状态：设计方案，未实现。
- 前置：[P02 合并与区域操作](phase-2.md) 已通过可见格、共享边界和内容保留验收。
- 总体完成门槛：[全功能分期总览](00-overview.md)。

## 用户可见目标

用户可以分别设置表格、行、列、单元格和背景文本的外观，给表格添加标题，复制格式，并在等比或不等比调整整个表格时得到确定的图形与文字结果。所有外观在画布、导出、保存重开后保持一致。

## 样式模型

- 表格提供外边框、内网格线、背景填充、透明度与样式预设；单元格提供填充和局部边框。行、列支持批量设置填充、边框及背景文本样式。
- 继承优先级固定为：单元格覆盖 > 行覆盖 > 列覆盖 > 表格默认。清除覆盖后恢复上一级样式，而不是写入当前主题的硬编码颜色。明暗主题色使用语义 token；自定义色保存实际色值。
- 内部共享边只渲染一次。相邻单元格同时设置不同边框时，显式单元格边优先于继承边；两侧同级冲突按稳定单元格 ID 决定优先级。合并区域内部边不渲染。表格外边框优先于内部边。
- 可选标题是通过正式标题绑定关联到表格的独立文本，每表至多一份；不占行列交点，不改变 P01 的网格 `width`/`height` 不变量。表格选择和导出范围包含标题。标题随表格移动和缩放，普通格内拖入不会命中标题。无标题时不保留占位高度。
- 样式字段作为正式表格结构保存；单元格、行列样式不得仅存在于视图状态。

## 文本与内容

- 背景文本可设置字体、字号、字重、斜体、下划线、删除线、颜色、水平/垂直对齐和内边距。直接输入、换行、复制粘贴、中文输入与画板文本编辑器一致。
- 普通格的背景文本框跟随单元格尺寸；合并格中锚点文本框跟随整个可见格，覆盖格各自的文本框保持所属基础格位置和尺寸，并遵循 P02 的命中规则。文本不自动撑大表格。过长内容保留原文；默认显示溢出，用户可为表格或单格开启裁切。裁切同时作用于画布、命中和导出，只影响显示，不改文字和子图形数据；编辑态可滚动到光标。
- “普通文本图形”保持独立画布属性和图层；将其拖入单元格不会改写背景文本或强制变成背景层。支持文本的普通图形仍可在外部单独切换 `auto` / `fixed` 模式。
- 样式复制只复制外观字段；对背景文本应用样式不会改写文字内容或附着的普通图形。多格、整行、整列应用使用同一批量命令和一次撤销。
- 选中单元格内多个普通图形时，可按可见格中心/边缘对齐或在格内分布；只改变所选图形的坐标，不写背景文本、不自动排列其他内容。

## 不等比整体拉伸

P01 的四角等比缩放继续保留。本期增加宽高分别变化的整体拉伸；拖动侧边控制柄只改变一个轴，拖动角控制柄可自由改变两个轴，按 Shift 保持等比。令 `sx = 新宽 / 原宽`、`sy = 新高 / 原高`，在拖动起点快照上一次计算全部后代，不逐帧累积。

| 对象 | `sx` / `sy` 处理 |
| --- | --- |
| 表格与单元格 | 列宽乘 `sx`，行高乘 `sy`；合并区域由基础格求和，标题随表格定位 |
| 普通几何图形、图片、路径、连接线 | 局部坐标的 X/Y 分别按 `sx`/`sy` 变换；图片比例约束若被启用则使用画板已有的裁切/留白规则，并在预览中可见 |
| 支持文本的图形与绑定文字 | 先转固定模式；文本框宽高分别按 `sx`/`sy`，字号统一乘 `min(sx, sy)`，按新宽重排，不反向撑大图形 |
| 独立文本、背景文本、标题 | 固定文本框，宽高分别按 `sx`/`sy`，字号乘 `min(sx, sy)`，按新宽重排；背景文本层级不变 |
| 嵌套表格 | 每层按同一变换递归一次；子表格内部行列及内容不能重复缩放 |

文字只有一个字号，不对字形本身做横向挤压；因此不等比拉伸允许换行改变，但文本内容、对齐方式、归属和层级保持不变。缩放预览先用固定模式排版，提交时永久切换；取消和零变化不改模式。最小尺寸约束以整棵嵌套表格子树为单位计算；任何后代触底时统一限制本次倍率，不能只停止一部分图形。P01 的局部行高/列宽调整规则不受影响。

## 外观操作与界面

- 属性面板按当前层级显示表格、行/列、区域或单格可用属性。混合值显示为未统一状态；调整时只写入所选目标。工具栏的颜色用色块、边框样式用菜单、对齐用图标或分段控件。
- 在单元格文本编辑态仅显示文字属性；背景文本的文字选择、普通图形的选择和格子选择不能混淆。未知图标提供名称和提示。
- 悬停与选中蓝色反馈不写入导出。实际底色、网格线、标题、文字及子图形在明暗主题下有足够对比度。
- 可提供“清除样式”和少量表格预设；预设只组合正式样式字段，应用后仍可逐项编辑。局部样式不会意外重置其他格的图形层级。

## 实施与验收

1. 建立表格/行/列/单元格样式解析和共享边几何，接入画布与 SVG/PNG 同一结果。
2. 接入标题、背景文本属性、样式面板、多选混合态、复制格式与清除覆盖。
3. 实现不等比拉伸的预览、子树几何、文字固定模式、边界约束和原子历史。

- [ ] 表格、行、列、单格的填充与边框优先级正确；合并内部无重复线，保存重开与导出一致。
- [ ] 背景文本支持全套列出的文字样式与对齐；普通文本图形不被误转为背景文本，长文本不撑大单元格。
- [ ] 格内图形对齐与分布不改归属或背景文本；默认溢出与可选裁切在画布、命中、保存和导出中一致。
- [ ] 标题不占单元格，移动、旋转、缩放、复制、导出和嵌套时与表格一致。
- [ ] 等比与不等比拉伸含合并格、自由绘制、连接线、图片及嵌套表格时无重复变换；固定模式、换行、最小尺寸、撤销重做符合规则。
- [ ] 明暗主题、普通画布与 PNG/SVG 使用同一颜色和边界；选中提示不进入导出。
