# 第三期：样式、文本与高级变换

- 状态：设计方案，未实现。
- 前置：[P02 合并与区域操作](phase-2.md) 已通过可见格、共享边界和内容保留验收。
- 总体完成门槛：[全功能分期总览](00-overview.md)。

## 用户可见目标

用户可以分别设置表格、行、列、单元格和背景文本的外观，给表格添加标题并复制格式。已有的表格移动、等比缩放和水平/垂直单轴缩放继续遵循 P01/P01.2 规则；本期不新增缩放能力。所有外观在画布、导出、保存重开后保持一致。

## 样式模型

- 表格提供外边框、内网格线、背景填充、透明度与样式预设；行、列支持批量设置填充和背景文本样式；单元格只提供填充。所有样式字段统一放在对应结构的 `style` 下。
- 继承优先级固定为：单元格覆盖 > 行覆盖 > 列覆盖 > 表格默认。清除覆盖后恢复上一级样式，而不是写入当前主题的硬编码颜色。明暗主题色使用语义 token；自定义色保存实际色值。
- 内部共享边只渲染一次，由表格统一的网格样式绘制；合并区域内部边不渲染。单元格不定义边框样式。
- 可选标题是通过 `containerRef: { type: "tableTitle", elementId: tableId }` 绑定到表格的独立文本，每表至多一份；不占行列交点，不改变 P01 的网格 `width`/`height` 不变量。表格选择和导出范围包含标题。标题随表格移动和已有缩放操作同步，普通格内拖入不会命中标题。删除表格同时删除标题，删除标题只解除绑定；复制表格时复制标题并重映射绑定。无标题时不保留占位高度。
- 样式字段作为正式表格结构保存；单元格、行列样式不得仅存在于视图状态。

基础样式字段统一放在对应结构的 `style` 下：

```ts
type TableStyle = {
  backgroundColor?: ColorToken | string;
  opacity?: number;
  borderColor?: ColorToken | string;
  borderWidth?: number;
  borderStyle?: "solid" | "dashed" | "dotted";
  gridColor?: ColorToken | string;
  gridWidth?: number;
  gridStyle?: "solid" | "dashed" | "dotted";
  clipContent?: boolean;
  title?: { gap?: number; align?: "start" | "center" | "end" };
};
type RowStyle = { backgroundColor?: ColorToken | string; backgroundText?: BackgroundTextStyle };
type ColumnStyle = { backgroundColor?: ColorToken | string; backgroundText?: BackgroundTextStyle };
type CellStyle = { backgroundColor?: ColorToken | string; clipContent?: boolean };
type BackgroundTextStyle = {
  fontFamily?: string;
  fontSize?: number;
  fontWeight?: number;
  italic?: boolean;
  underline?: boolean;
  strikethrough?: boolean;
  color?: ColorToken | string;
  horizontalAlign?: "left" | "center" | "right";
  verticalAlign?: "top" | "middle" | "bottom";
  padding?: number;
};
```

## 文本与内容

- 背景文本可设置字体、字号、字重、斜体、下划线、删除线、颜色、水平/垂直对齐和内边距。直接输入、换行、复制粘贴、中文输入与画板文本编辑器一致。
- 背景文本框跟随单元格或合并可见格尺寸；按 P02，各来源文案合入锚点格的背景文本并使用保留元素的样式，覆盖格没有独立的背景文本框；拆分后不自动分回原格。表格不提供内容驱动尺寸模式，过长内容保留原文并默认溢出。用户可在表格或单格的 `style.clipContent` 开启显示裁切；裁切同时作用于画布、命中和导出，只影响显示，不改文字和子图形数据；编辑态可滚动到光标。
- “普通文本图形”保持独立画布属性和图层；将其拖入单元格不会改写背景文本或强制变成背景层。支持文本的普通图形仍可在外部单独切换 `auto` / `fixed` 模式。表格已有缩放操作提交尺寸变化时，将内部支持文本的普通图形、绑定文字和其他可固定布局的图形统一设置为 `fixed`；拖入单元格、行列调整和普通移动不改变该模式。
- 样式复制只复制外观字段；对背景文本应用样式不会改写文字内容或附着的普通图形。多格、整行、整列应用使用同一批量命令和一次撤销。
- 选中单元格内多个普通图形时，可按可见格中心/边缘对齐或在格内分布；只改变所选图形的坐标，不写背景文本、不自动排列其他内容。

## 外观操作与界面

- 属性面板按当前层级显示表格、行/列、区域或单格可用属性。混合值显示为未统一状态；调整时只写入所选目标。工具栏的颜色用色块、边框样式用菜单、对齐用图标或分段控件。
- 在单元格文本编辑态仅显示文字属性；背景文本的文字选择、普通图形的选择和格子选择不能混淆。未知图标提供名称和提示。
- 悬停与选中蓝色反馈不写入导出。实际底色、网格线、标题、文字及子图形在明暗主题下有足够对比度。
- 可提供“清除样式”和少量表格预设；预设只组合正式样式字段，应用后仍可逐项编辑。局部样式不会意外重置其他格的图形层级。

## 实施与验收

1. 建立表格/行/列/单元格样式解析和共享边几何，接入画布与 SVG/PNG 同一结果。
2. 接入标题、背景文本属性、样式面板、多选混合态、复制格式与清除覆盖。
3. 接入已有缩放提交规则：尺寸实际变化时统一持久化后代 `fixed` 模式；不改变 P01/P01.2 的几何算法。

- [ ] 表格、行、列、单格的填充与边框优先级正确；合并内部无重复线，保存重开与导出一致。
- [ ] 背景文本支持全套列出的文字样式与对齐；普通文本图形不被误转为背景文本，长文本不撑大单元格。
- [ ] 格内图形对齐与分布不改归属或背景文本；默认溢出与可选裁切在画布、命中、保存和导出中一致。
- [ ] 标题不占单元格，移动、缩放、复制、导出和嵌套时与表格一致。
- [ ] 已有等比、水平单轴和垂直单轴缩放不改变表格结构；尺寸实际变化时内部支持文本的图形统一持久化为 `fixed`，取消和零变化不改变模式。
- [ ] 标题创建、编辑、删除、移动、已有缩放、复制和撤销重做符合标题绑定规则。
- [ ] 样式、标题、背景文本和普通图形复制后 ID、绑定和图层独立；复制不删除源对象。
- [ ] 样式、标题、复制、背景文本编辑和普通图形模式切换各自只产生一条历史记录，保存重开后结果一致。
- [ ] 明暗主题、普通画布与 PNG/SVG 使用同一颜色和边界；选中提示不进入导出。

## 人工验收场景

每个场景均检查画布、PNG/SVG、保存重开、撤销和重做；复制场景还需确认源对象保留且副本可独立编辑：

1. 设置表格填充、透明度、外框和网格线，确认合并区域内部不重复绘线。
2. 分别设置表格、行、列和单元格填充，清除各级覆盖，确认继承优先级和恢复结果。
3. 设置背景文本的字体、字号、字重、斜体、装饰线、颜色、对齐和内边距，验证中文输入、换行和粘贴。
4. 将独立文本、便签和带文字图形拖入单元格，确认背景文本不被改写，普通图形仍可单独切换 `auto` / `fixed`。
5. 合并含背景文本的区域并拆分，确认文案、样式、图层和撤销结果符合 P02 规则。
6. 创建、编辑、移动、已有缩放、删除和复制标题，确认标题不占单元格且绑定无悬空。
7. 使用四角等比、四边水平和垂直单轴缩放，确认结构不变；尺寸变化提交后内部支持文本图形变为 `fixed`，取消或零变化不改变模式。
8. 在表格内选择多个普通图形执行对齐和分布，确认只改变坐标，不改变归属、背景文本或其他图形。
9. 测试默认溢出与开启显示裁切，确认画布、命中、编辑态和 PNG/SVG 结果一致，原文和子图形数据不变。
10. 复制整表、合并区域、单个图形和嵌套表格，确认样式、背景文本、标题、绑定文字、内部图形和 ID 映射完整，源对象保留。
11. 复制含两端都在表格内以及只有一端在表格内的箭头，确认两类关联均按复制规则处理，不产生静默丢失或错误绑定。
12. 在明暗主题下重复上述操作，确认语义颜色跟随主题、自定义颜色保持原值，悬停和选中反馈不进入导出。
