## 用户可见目标

用户可以复制整张表格、行列、单元格区域或内部图形，粘贴到画布或另一张表格，保存为库项目，导入原生文件和 Lark 表格类数据，并导出可复用的完整结果。复制或转换不能丢失图形、背景文本、合并关系、样式及嵌套结构。

## 剪贴板与库

| 来源 | 粘贴目标 | 规则 |
| --- | --- | --- |
| 整张表格 | 画布或另一单元格 | 深拷贝全部行列、基础格、合并、标题、背景文本及后代；重新生成 ID 与绑定引用 |
| 连续行/列 | 同表或另一表 | 保留行/列尺寸、相交格样式与内容；必要时扩展目标结构，预览插入位置 |
| 矩形单元格区域 | 同表或另一表 | 复制格尺寸、合并、背景文本和子图形；目标与现有合并格冲突时先预览并提示，不静默覆盖 |
| 单个普通图形 | 单元格或画布 | 只复制该图形及其绑定文字；按新落点决定归属，不复制所在表格 |
| 表格区域的纯文本 | 外部应用 | 按可见格输出 TSV；普通图形不转成文本，嵌套表格不被压平成未知字符串 |
| 外部 TSV | 表格选中区域 | 预览写入的背景文本范围；仅覆盖背景文本，普通图形保留，必要扩展行列后一次提交 |

剪切与复制使用同一结构快照；剪切只有在成功写入剪贴板后才删除原对象。区域粘贴遇冲突时让用户选择取消、覆盖目标背景文本/样式或插入新行列；任何选项都不无提示删除目标普通图形。复制后新表可与原表独立编辑，撤销分别恢复源与目标。库项目保存与实例化使用同一深拷贝及校验，不以一张扁平图片替代。

## 原生格式与宿主 API

- `.excalidraw`、`.excalidrawlib`、剪贴板元素数组、初始数据与公开 API 都接收规范表格结构。加载时校验版本、单元格矩形、稳定 ID、归属、合并关系、标题绑定及嵌套无环；旧期数据按已定义迁移链升级。
- 导出 PNG/SVG 时显示表格和全部可见后代，不导出悬停、选中、插入线或对齐辅助线。独立选中表格导出要包含可见溢出内容及标题；画布全图导出按场景层级绘制。
- 与画框、分组、链接、锁定、箭头绑定、图层顺序及复制粘贴的现有语义协作：表格关系不能覆盖 `frameId` 或 `groupIds`，外部箭头绑定在复制、移动、导出后不得悬空。
- 部分选区只包含表格后代时，导出/复制按显式选中对象处理；用户选择整个表格时必须包含完整子树。混选普通元素和表格时只遍历每个 ID 一次。

## Lark 表格类互通

现有样本有 `table`、`table_er`、`table_uml` 和 `combined_fragment` 四类。导入器按实际源 `type` 分流：普通 `table` 建立网格容器；`table_er`、`table_uml` 在正式表格结构中保留 `kind` 变体，并使用对应外观预设和可编辑网格；`combined_fragment` 使用独立语义类型，复用网格与单元格引擎但不冒充普通表格。变体标识必须随原生保存、复制和导出保留。变体专属外观及交互需逐样本和产品界面核对，不能只凭类型名称推断。

| 源字段 | 目标与校验 |
| --- | --- |
| `table.meta.row_num`、`col_num`、`row_sizes`、`col_sizes` | 建立有序行列；数量、有限正数和尺寸长度必须匹配 |
| `table.cells[].row_index`、`col_index` | 映射到稳定基础格 ID；校验索引基数、范围和重复记录 |
| `merge_info.row_span`、`col_span` | 映射 P02 合并关系；越界或相互重叠时报错 |
| 格的 `style`、`text` | 映射 P03 填色、透明度、主题色及背景文本样式；空文本不创建多余可见文字 |
| `table.meta.style`、`meta.text`、`title` | 映射表格默认样式、文字默认值和可选标题；不覆盖格级显式样式 |
| 源 `x`、`y`、`width`、`height`、`angle`、`z_index` | 映射画布几何与顺序；与内部行列尺寸冲突时按下面的归一化规则处理 |

部分样本的 `col_sizes`/`row_sizes` 之和与外部 `width`/`height` 不一致。导入时以外框宽高为可见结果，将列宽按 `width / sum(col_sizes)`、行高按 `height / sum(row_sizes)` 归一化，并记录诊断；若外框或尺寸无效，拒绝该表而不吞掉其他画布元素。保留经类型校验的来源几何用于未编辑对象的 Lark 回写；几何编辑后输出规范化尺寸。所有语义损失或未映射字段在导入/导出结果中列明，不能静默丢弃。

Lark 导出以已核实字段为目标，至少包含普通表格及三种样本变体的已知结构、文字、颜色和几何。目标格式无法表达任意嵌套画板图形、复杂绑定或自定义样式时，导出前给出可审查的损失报告，用户选择继续后才生成降级结果；原生 Excalidraw 格式仍保持完整数据。导入后保存为原生文件必须无损，Lark 再导出要求语义和画面可验收，不要求原始 JSON 字节相同。

## 实施与验收

1. 抽取深拷贝、重映射和结构快照，覆盖表格、区域、行列、嵌套及混选。
2. 接入剪贴板多格式、库、原生文件/API 和图像导出；保存、恢复、重复恢复共用校验。
3. 建立 Lark 四类映射、归一化、来源诊断、损失预览及样本回归。

- [ ] 整表、行列、合并区域、单图形和嵌套表格的复制剪切粘贴结果相互独立，无重复/悬空 ID。
- [ ] TSV 粘贴仅改变预览中指明的背景文本；普通图形与目标合并关系不被悄然破坏。
- [ ] 文件、库、剪贴板、公开 API、PNG/SVG 往返保持可见内容和结构；异常输入明确反馈。
- [ ] 11 个现有 Lark 表格类样本均有明确处理结果，合并、标题、样式、几何及变体类型可核对；不支持字段有损失报告。
- [ ] 混选、画框、分组、锁定和跨表箭头绑定与表格互不破坏。
