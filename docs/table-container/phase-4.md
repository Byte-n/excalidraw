## 用户可见目标

用户可以复制整张表格、行列、单元格区域或内部图形，粘贴到画布或另一张表格，保存为库项目，通过原生文件和公开 API 复用完整结构。复制、保存和恢复不能丢失图形、背景文本、合并关系、样式及嵌套结构。当前不提供剪切命令，复制后源对象保留。

## 剪贴板与库

| 来源 | 粘贴目标 | 规则 |
| --- | --- | --- |
| 整张表格 | 画布或另一单元格 | 深拷贝全部行列、基础格、合并、标题、样式、背景文本及后代；重新生成 ID 与绑定引用 |
| 连续行/列 | 同表或另一表 | 作为矩形单元格区域按目标位置一一对应覆盖；源尺寸、样式和内容写入对应格，目标空间不足时只向尾部扩展行列 |
| 矩形单元格区域 | 同表或另一表 | 复制格尺寸、样式、背景文本和子图形；目标范围涉及合并冲突时直接拒绝并提示 |
| 单个普通图形 | 单元格或画布 | 复制该图形及其绑定文字；按新落点决定归属，不复制所在表格 |
| 表格区域的纯文本 | 外部应用 | 按可见格输出 TSV；普通图形不转成文本，嵌套表格不被压平成未知字符串 |
| 外部 TSV | 表格选中区域 | 按同一矩阵映射写入背景文本；空字段清空目标背景文本，普通图形和样式保留，必要时扩展行列后一次提交 |

复制使用操作开始时取得的完整结构快照；源对象始终保留。单元格、连续行或连续列均转换为矩形快照，非连续选择先合并为覆盖其范围的连续矩形，再按矩形位置映射。以目标单元格为矩形左上角逐格覆盖；目标行列不足时只在尾部创建缺少的行列，新行列使用源尺寸。源行高、列宽覆盖对应目标尺寸，源单元格样式覆盖目标样式；源单元格没有背景文本时清空目标背景文本。

单元格矩阵粘贴不插入整行或整列，也不显示插入预览。源与目标范围的合并关系发生任何冲突时，整个操作原子拒绝并提示。普通图形全部生成新 ID，保留相对所属单元格的位置并追加到目标单元格内容顶层；源图形不会替换目标图形。复制范围内的连线也生成新 ID并复制；两端都在范围内时重建与副本的连接，范围外端点在副本中断开，连线相对目标单元格的长度和位置保持不变。单元格矩阵粘贴暂不支持嵌套表格；选中包含嵌套表格的单元格时拒绝该粘贴。

粘贴到画布空白区域时，按源矩形创建独立表格，保留源行列尺寸并创建全部空单元格；同时选中单元格和外部普通图形时按完整选区复制，只能粘贴到画布空白区域，不能粘贴到已有表格。锁定或只读目标、无效结构、重复 ID、尺寸错误或其他校验失败时原子拒绝，不产生部分结果。扩展行列、样式替换、背景文本替换、图形追加和结构变化共用一条撤销记录；同表重叠粘贴始终从初始快照读取。库项目保存与实例化使用同一深拷贝及校验，不以一张扁平图片替代。

## 原生格式与宿主 API

- `.excalidraw`、`.excalidrawlib`、剪贴板元素数组、初始数据与公开 API 都接收新版本的规范表格结构。加载时校验版本、单元格矩形、稳定 ID、归属、合并关系、标题绑定及嵌套无环。
- 本期及整个表格大版本不迁移、不兼容历史文件、库项目、剪贴板数据或旧客户端；不提供兼容别名、降级读取或静默修复，正常按新数据处理就行，不需要识别提示旧格式等错误。
- 导出 PNG/SVG 时显示表格和全部可见后代，不导出悬停、选中、插入线或对齐辅助线。独立选中表格导出要包含可见溢出内容及标题；画布全图导出按场景层级绘制。
- 与画框、分组、链接、锁定、箭头绑定、图层顺序及复制粘贴的语义协作：画框与表格单元格共用规范直接父引用，`groupIds` 保持独立；复制和导出须遍历父链。单元格矩阵粘贴只保留复制范围内的连线绑定，范围外绑定在副本中断开。
- 部分选区只包含表格后代时，导出/复制按显式选中对象处理；用户选择整个表格时必须包含完整子树。混选普通元素和表格时只遍历每个 ID 一次。

## 实施与验收

1. 抽取深拷贝、重映射和结构快照，覆盖表格、矩形区域、行列、同表重叠及混选。
2. 接入剪贴板多格式、库、原生文件/API 和图像导出；保存、恢复、重复恢复共用校验。
3. 覆盖画框包裹表格、混选及含内部绑定图形的文件、库、剪贴板和 API 往返；对缺失目标、无效尺寸、重复 ID、锁定目标和父链环给出确定结果。

- [ ] 整表、行列、矩形区域和单图形的复制粘贴结果相互独立，无重复 ID；源对象保留，不提供剪切命令；单元格矩阵粘贴不支持嵌套表格。
- [ ] TSV 粘贴按同一矩阵映射写入背景文本；空字段清空目标背景文本，普通图形和样式保持不变。
- [ ] 文件、库、剪贴板、公开 API、PNG/SVG 往返保持可见内容和结构；异常输入明确反馈。
- [ ] 复制或恢复含合并格、标题、背景文本和多层父链的表格后，全部引用指向对应副本；不合法结构被明确拒绝。
- [ ] 混选、画框、分组、锁定和内部箭头绑定与表格互不破坏；锁定或只读目标原子拒绝。
- [ ] 复制含样式、背景文本、标题、内部图形及复制范围内连线的表格后，复制对象和内部绑定按规则重建，范围外连接断开，保存重开结果一致。
