# P01.1：表格适应内容模式

- 状态：补充设计方案，未实现。
- 前置：[P01 表格容器](phase-1.md) 的稳定单元格归属、行列尺寸、背景文本和撤销能力。
- 定位：为单张表格增加可选的内容驱动尺寸模式；默认行为仍是 P01 的固定尺寸与内容越格显示。
- 后续衔接：[P02 合并单元格](phase-2.md) 须扩展可见合并格的尺寸需求分配；[P03 样式与文本](phase-3.md) 的裁切及不等比拉伸须遵守本模式。

## 用户可见目标

选中表格后，可在属性面板的“尺寸模式”分段控件中选择“固定尺寸”或“适应内容”。固定尺寸沿用 P01：内容可以越格，行列仅随用户的结构操作或整表缩放变化。适应内容时，格内内容超出右边或下边的空间需求会扩张所属列或行；背景文本只会根据当前列宽撑高所在行。模式作用于整张表，不由格内图形自行切换，也不改变单元格归属、图层或文字内容。

默认新表格为固定尺寸。切换到适应内容时，对当前内容计算一次需求，必要时扩张；切回固定尺寸时保留当时尺寸。内容移走、删除或变小不会自动收缩表格，以免其他格和外部连接线突然跳动。用户可拖动分隔线缩小行列，或在适应内容模式下使用“重置手动最小尺寸”命令，将所有手动下限恢复为产品的最小行列尺寸后重新按内容计算；该命令须有明确预览和一次撤销。内容仍大于用户要求的尺寸时，行列保持足以容纳内容的尺寸，界面提示限制来源。

## 数据契约

在 P01 的 `TableDataV1` 中增加可选字段；未出现 `sizingMode` 的现有表格按 `fixed` 处理，不改写旧文件或在加载时重排内容。

```ts
type TableSizingMode = "fixed" | "fitContent";

type TableDataV1SizingExtension = Readonly<{
  sizingMode?: TableSizingMode;
  rows: readonly { id: string; height: number; minHeight?: number }[];
  columns: readonly { id: string; width: number; minWidth?: number }[];
}>;
```

- `height`、`width` 仍是唯一持久化的实际尺寸；表格元素的 `height`、`width` 仍分别等于行高、列宽之和。不另存内容测量结果、单元格几何或子图形偏移。
- `fitContent` 模式下每行 `minHeight`、每列 `minWidth` 必填，表示用户设定的尺寸下限；实际尺寸必须不小于下限。切换模式时以切换前的实际尺寸初始化下限；插入行列时以新行列的初始尺寸作为下限；拖动分隔线修改对应下限，并在同一操作中重新计算实际尺寸。重置命令将所有下限设为当前产品最小行列尺寸，不以内容计算值反写下限。删除和排序时，下限随稳定行列 ID 一同删除或移动。切回 `fixed` 时去掉下限字段，保留实际尺寸。
- 既有 1 版结构增加可选字段，不更换 ID 或改变缺省语义。校验模式枚举、下限为有限正数、适应内容模式下下限完整、固定尺寸模式下无下限字段、实际尺寸不小于下限；复制、库、剪贴板、公开 API、恢复和协作提交均保留这些字段。现有结构命令重建 `table` 对象时也须透传模式及下限。
- 内容需求是派生值，不在文件加载时重新计算。不同浏览器的字体或图片加载时机不得悄悄改写已保存几何；只有下文列出的明确编辑操作才提交新尺寸。

## 尺寸计算

一次计算使用操作开始时的表格和成员快照，先算列宽，再按计算后的列宽测量背景文本并算行高。每行列的新尺寸取当前尺寸、手动下限和内容需求的最大值；因此普通内容编辑只扩张，不收缩。用户主动缩小分隔线或执行重置命令时，允许从新下限及当前内容需求重新求值。行列正的最小尺寸约束始终生效。

| 内容 | 所属行列的需求 |
| --- | --- |
| 单元格背景文本 | 使用当前列宽减去文本内边距，按实际字体、换行和行距计算完整文本高度；只影响所属行高，不据文本长度撑宽列，也不以文本框当前高度作为需求。 |
| 普通图形、独立文本、图片和自由绘制 | 以其可见边界在表格局部坐标中的最右、最下位置，减去所属格左上角位置，再加格内间距；分别形成所属列、行的需求。 |
| 分组、画框、便签、思维导图及绑定文字 | 按语义根和可见后代的边界并集测量；同一后代只计一次，保持其原有归属与布局规则。 |
| 嵌套表格 | 先从内到外完成子表格的尺寸计算，再把子表格及其可见后代边界计入父格；固定尺寸子表格只按其现有几何计入。 |

只有属于该格的内容参与该格的计算；视觉上越入相邻格的图形仍由原格负责。内容向左或向上越过格边时继续按 P01 显示溢出，不能靠增加右侧列宽或下方行高修复，也不改变归属。旋转图形的可见边界需先转换到所属表格的局部轴再求需求；线条和跨格绑定连接线按可见路径计入所属格，但表格外的绑定对象不因此成为成员。无法得到稳定自然尺寸的资源保留已有几何，资源就绪后只有明确的用户编辑才触发重算。

列扩张会改变后续列的起点，行扩张会改变后续行的起点。以表格局部左上角为扩张锚点，把行列偏移转换成场景位移，保持每个成员相对所属格的位置。成员沿 P01 的行列位移规则平移，所属格内图形不缩放，背景文本框再跟随新格几何；嵌套表格的后代随父表格平移一次。一次操作从同一快照计算和提交，避免反复测量导致漂移。背景文本的测量须复用画板文字排版规则；计算只读其内容，不改写文字模式或原文。

## 触发与交互

- 在适应内容模式下，完成背景文本编辑、拖入或移出、格内图形移动/缩放/旋转、粘贴、复制生成、删除、嵌套表格结构变化时，重算受影响的表格及其适应内容的祖先表格。拖拽过程只预览，提交时连同成员位移、绑定更新形成一条撤销记录；取消或没有尺寸变化不产生额外记录。
- 行列插入、删除、排序沿用 P01 命令；插入后新行列按邻近尺寸设下限，再计算需求。局部尺寸拖动显示用户请求值与内容限制后的实际值，释放后只提交一次。模式切换和“重置手动最小尺寸”也是各自独立的一次撤销操作。
- 整表等比缩放保持 P01 规则：实际尺寸、手动下限和全部后代同倍率变换，不在缩放预览每帧重排文字。完成后保留原模式；后续内容编辑才按该模式重新测量。P03 不等比拉伸也须同步变换下限并沿用此提交边界。
- 表格选中态显示当前模式；行列尺寸受到内容限制时显示原因。键盘可以到达模式切换和重置命令，触屏入口不依赖悬停。编辑文本和输入法组合期间不触发结构快捷键。

## 与后续期次的边界

P01.1 只处理未合并的基础格。P02 引入合并格后，须基于可见合并格的总宽高计算需求，并定义多行多列间的增量分配；在该规则实现前，适应内容模式下的合并命令不可用，不能让合并格继续以 P01.1 的基础格算法自动扩张。P03 的裁切只改变显示，不改变内容需求；即使视觉被裁切，适应内容模式仍按完整内容计算。P03 的标题不占网格行列，也不参与格内需求。

本期不加入按单元格配置模式、内容删除后的自动收缩、向左/向上自动扩张、自动居中、自动换列、依文本长度撑宽背景文本所在列，或跨多格自动分摊普通图形尺寸。并发编辑沿用 P01 的结构提交边界；自动尺寸与原编辑作为同一个结果提交，冲突重放后必须校验表格尺寸和下限，不以客户端重排替代并发合并规则。

## 实施顺序

1. 扩展结构类型、校验、工厂、恢复和所有表格结构命令；覆盖模式切换、下限、复制及文件/库/剪贴板往返。
2. 建立格内内容需求测量与自内向外的嵌套计算；复用行列成员平移及背景文本框更新，处理旋转、绑定和语义子树去重。
3. 接入编辑提交、拖放预览、属性面板分段控件、手动尺寸反馈和重置命令；统一撤销重做与协作提交。
4. 验证文字排版、异步资源、保存重开、导出、明暗主题、中文输入、触屏及大表性能；再与 P02/P03 的合并格和裁切规则联测。

## 验收清单

- [ ] 新表格默认为固定尺寸；旧场景加载不改变几何。切换到适应内容会按现有内容扩张；切回后保留尺寸，保存重开、复制和撤销重做保留正确模式。
- [ ] 背景文本在固定列宽内换行并只撑高所属行；普通图形、分组和嵌套表格按所属格的右侧、下侧需求扩张；左侧、上侧溢出不改归属。
- [ ] 多个图形、旋转、跨格绑定、嵌套表格及语义子树不会重复计量或重复平移；列宽先于文本行高计算，结果稳定。
- [ ] 删除或移走内容不会自动缩小；手动调整和重置命令可以在内容允许时缩小，内容不足空间时不会把格压到需求以下，反馈明确。
- [ ] 拖放预览与提交、取消、撤销重做一致；一次用户操作只有一条历史记录，保存重开及 PNG/SVG 导出与画布几何一致。
- [ ] 键盘、鼠标、触屏和中文输入法下可切换模式及编辑内容；大表重算不出现明显卡顿，非法模式与下限数据在各入口明确报错。
