# P01.1：表格适应内容模式

- 状态：取消。
- 原因：表格不提供 `fixed` / `fitContent` 尺寸模式，行列不会因单元格内容自动扩张或收缩。

表格沿用 P01 的固定几何规则：背景文本和普通图形可以溢出单元格，用户通过行列尺寸操作调整表格结构。背景文本框跟随所属单元格或合并可见格的几何，内容不会自动改写行高或列宽。

普通图形的文字布局仍由图形自身的 `auto` / `fixed` 模式控制。表格已有缩放操作实际提交尺寸变化时，内部支持文本的普通图形、绑定文字和其他可固定布局的图形统一设置为 `fixed`；拖入单元格、行列调整和普通移动不改变该模式。

本文件保留为历史分期索引，不再增加数据字段、尺寸计算、模式切换或相关验收项。
