## 用户可见目标

用户可以选择连续的矩形单元格范围，合并和拆分跨行跨列区域，批量处理行列与格子，并且不会因结构修改丢失单元格背景文本或内部图形。合并后的区域仍是容器，可继续拖入任意图形及嵌套表格。

## 数据与几何

- 在每个行列交点结构上增加合并关系：左上角为锚点，记录 `rowSpan`、`columnSpan`；其余覆盖格仍保留稳定 ID，记录锚点 ID，但不单独画边框。合并矩形不得重叠或越界，合并字段属于正式表格结构。
- 命中、对齐、文字框、插入线、导出按**可见格**的并集几何工作。合并时把范围内的子图形及嵌套表格统一转属左上角锚点格，保持世界坐标、层级和绑定；合并后新增内容也归属锚点格。覆盖格保留稳定 ID，但不再保存内容。拆分只恢复基础格边框和可见性，不重分配内容或移动图形；锚点格保留全部内容，其余恢复的格内容为空。
- 每个基础格最多一份背景文本。合并时按行优先、列次之的顺序读取范围内非空的背景文案，以一个换行符连接为锚点格唯一的背景文本；各段原有换行不改。优先复用锚点格已有的背景文本元素及样式；若锚点格没有背景文本元素，则复用顺序中的第一个非空背景文本元素及其样式并改属锚点格。其余来源背景文本元素在合并提交时移除，撤销合并可恢复原元素及 ID。合并格双击进入这一份背景文本的编辑；拆分后完整文案仍留在锚点格，不还原原格的分段、样式或背景文本元素。
- 边框绘制忽略合并区域内部边；外缘只绘一次。缩放、对齐和打印均使用同一合并几何。

## 选择与命令

- 桌面端先点击单元格确定起点，再按住 Shift 点击同一表格的另一格确定终点；再次 Shift 点击可调整终点。单元格范围不支持鼠标拖选，画布中普通图形原有的框选不受影响。键盘聚焦单元格后，Shift + 方向键扩展范围；不带 Shift 的方向键移动焦点并结束范围选择。所有入口都形成起点与终点之间的矩形范围，不逐格累加不连续选择。
- 手机和平板选中单元格后，在其上下文工具栏显示“单元格多选”开关。开启时以当前格为起点，点击同一表格的另一格确定矩形范围；继续点击其他格只调整终点，不重置起点。模式内点击格内子图形、背景文本或空白区域都只命中所属的可见单元格，不选中或编辑图形及文字；单指拖动不移动格内内容或形成选区。开关保持可见并标明开启状态；再次点击开关或点击“完成”退出多选模式并保留当前选区，点击“取消选择”则退出并清除选区。退出后恢复普通单格与格内图形的点击行为。移动端不支持从表格内拖动框选，双指仍用于画布平移/缩放；外接键盘仍可使用 Shift + 点击和 Shift + 方向键。
- 移动端单元格多选模式只作用于进入模式时所在的表格。点击画布空白、其他图形或另一张表格时，阻止该次点击，不改变选区或退出模式，并提示“请先退出单元格多选”；工具栏中的范围命令和退出入口仍可操作。
- 各入口的范围只要碰到合并格，就扩展到包含该合并格的全部行列，重复直到稳定；UI 显示最终范围。点击合并格的任意位置都以该可见格的完整跨度计算范围，移动端调整终点时实时更新预览。
- 合并仅作用于至少两个可见格构成的矩形；不能选择不连续格、跨表格格或仅合并格的一部分。命令在工具栏与上下文菜单可见，禁用时说明原因。
- 拆分选择一个或多个完整合并格，仅解除合并关系并恢复原基础格的边线与独立命中；合并后的背景文案与全部子图形留在各自左上角锚点格，其余恢复的格内容为空。不提供内容分配或拆分策略选项。普通格上的拆分命令禁用。合并和拆分都只产生一次撤销记录。
- 区域操作包括清空内容、清空背景文本、清空样式、复制格式、批量对齐；三种“清空”使用分开的命令，避免误删嵌套图形。删除结构仍需明确选择行/列删除命令。
- 多行/多列可一起选中、移动和调整尺寸；拖动排序的移动单位包含合并区域涉及的所有行或列。不能完整移动时给出明确提示，不暗中拆散合并格。

## 与行列操作的关系

| 操作 | 与合并区域相交时的规则 |
| --- | --- |
| 在合并区域内部插入行/列 | 合并跨度增加，新基础格并入同一锚点；已有内容位置不变 |
| 在合并区域外缘插入行/列 | 新行/列不自动加入该合并格 |
| 删除部分合并区域覆盖的行/列 | 缩小跨度；若原锚点被删，转到剩余区域左上格并重映射归属 |
| 删除合并区域的全部行/列 | 连同背景文本和后代图形删除，可一次撤销 |
| 拖动排序穿过合并区域 | 只能整体移动受影响的连续行/列块；非法目标不提交 |
| 拖动合并区域内部边界 | 内边不可调整；外边按 P01 行高/列宽规则调整 |

删除锚点但仍保留合并区域时，原锚点的普通图形和背景文本转属剩余区域左上角的新锚点；普通图形保持画布位置，背景文本框按新的可见合并格重新计算，内容和样式保留。原覆盖格按上述归属规则为空，不发生背景文本冲突。仅当整个合并区域被删除才删除其内容。覆盖格的稳定 ID 与归属重映射必须在撤销/重做、复制和协作重放中一致。

## 界面与异常反馈

- 选区蓝色范围框与表格蓝色外框在层级上区分；合并格悬停只出现一个可见格高亮，背景文本不会阻挡范围选择。
- 拖入图形时命中合并格的任意部分都指向其锚点可见格；图形落点与对齐线基于整个合并区域，不能误吸附到隐藏内边界。
- 合并格只有锚点格的一份背景文本；各来源文案在其中连续编辑。文本编辑与 IME 行为沿用 P01，不因范围快捷键被打断。
- 粘贴或导入不完整合并数据、重叠合并关系、越界跨度时拒绝该结构并明确报错，不丢弃其中图形。
