# 第二期：合并单元格与区域操作

- 状态：设计方案，未实现。
- 前置：[P01 核心容器](phase-1.md) 已通过创建、归属、基础行列、保存和撤销验收。
- 总体完成门槛：[全功能分期总览](00-overview.md)。

## 用户可见目标

用户可以框选连续单元格，合并和拆分跨行跨列区域，批量处理行列与格子，并且不会因结构修改丢失单元格背景文本或内部图形。合并后的区域仍是容器，可继续拖入任意图形及嵌套表格。

## 数据与几何

- 在每个行列交点结构上增加合并关系：左上角为锚点，记录 `rowSpan`、`columnSpan`；其余覆盖格仍保留稳定 ID，记录锚点 ID，但不单独画边框。合并矩形不得重叠或越界，合并字段属于正式表格结构。
- 命中、对齐、文字框、插入线、导出按**可见格**的并集几何工作；格内子图形与背景文本仍按原基础格 ID 保存，合并与拆分不改其世界坐标。渲染时，所有基础格背景文本仍在该可见合并格普通图形之下。
- 每个基础格最多一份背景文本。合并后双击文字所在区域编辑该份文字；双击合并格其余空白区域编辑锚点格的文字。多份背景文本继续显示在原位置，不能覆盖或删除。拆分后原格、文本和内容自然恢复，无需猜测分配目标。
- 边框绘制忽略合并区域内部边；外缘只绘一次。旋转、缩放、对齐和打印均使用同一合并几何。

## 选择与命令

- 鼠标拖选、Shift 扩展、键盘方向键选择形成矩形范围。范围只要碰到合并格，就扩展到包含该合并格的全部行列，重复直到稳定；UI 显示最终范围。
- 合并仅作用于至少两个可见格构成的矩形；不能选择不连续格、跨表格格或仅合并格的一部分。命令在工具栏与上下文菜单可见，禁用时说明原因。
- 拆分选择一个或多个完整合并格，恢复原基础格的边线、背景文本和内容。普通格上的拆分命令禁用。合并和拆分都只产生一次撤销记录。
- 区域操作包括清空内容、清空背景文本、清空样式、复制格式、批量对齐；三种“清空”使用分开的命令，避免误删嵌套图形。删除结构仍需明确选择行/列删除命令。
- 多行/多列可一起选中、移动和调整尺寸；拖动排序的移动单位包含合并区域涉及的所有行或列。不能完整移动时给出明确提示，不暗中拆散合并格。

## 与行列操作的关系

| 操作 | 与合并区域相交时的规则 |
| --- | --- |
| 在合并区域内部插入行/列 | 合并跨度增加，新基础格并入同一锚点；已有内容位置不变 |
| 在合并区域外缘插入行/列 | 新行/列不自动加入该合并格 |
| 删除部分合并区域覆盖的行/列 | 缩小跨度；若原锚点被删，转到剩余区域左上格并重映射归属 |
| 删除合并区域的全部行/列 | 连同背景文本和后代图形删除，可一次撤销 |
| 拖动排序穿过合并区域 | 只能整体移动受影响的连续行/列块；非法目标不提交 |
| 拖动合并区域内部边界 | 内边不可调整；外边按 P01 行高/列宽规则调整 |

删除锚点但仍保留合并区域时，原锚点的普通图形转属新锚点且保持画布位置；原锚点背景文本若与新锚点已有背景文本冲突，则转成同位置的普通文本图形，否则作为新锚点背景文本。其内容与样式均保留。仅当整个合并区域被删除才删除其内容。覆盖格的稳定 ID 与归属重映射必须在撤销/重做、复制和协作重放中一致。

## 界面与异常反馈

- 选区蓝色范围框与表格蓝色外框在层级上区分；合并格悬停只出现一个可见格高亮，背景文本不会阻挡范围选择。
- 拖入图形时命中合并格的任意部分都指向其锚点可见格；图形落点与对齐线基于整个合并区域，不能误吸附到隐藏内边界。
- 对含多份背景文本的合并格，编辑入口突出实际命中的文本区域；文本编辑与 IME 行为沿用 P01，不因范围快捷键被打断。
- 粘贴或导入不完整合并数据、重叠合并关系、越界跨度时拒绝该结构并明确报错，不丢弃其中图形。

## 实施与验收

1. 建立基础格到可见格的索引、合并矩形校验和共享边界几何。
2. 接入范围选择、合并/拆分、区域清空与行列结构命令，统一历史提交。
3. 覆盖缩放、嵌套、绑定、复制、导出和重复恢复；渲染与命中使用同一可见格模型。

- [ ] 横向、纵向及二维合并/拆分后，全部背景文本、图形、层级和 ID 保留；保存重开再拆分结果一致。
- [ ] 选区碰到合并格会完整扩展；键盘、鼠标、上下文菜单对同一区域得到相同结构。
- [ ] 插入、删除、排序、调整尺寸与合并格相交时符合上表；每项一次撤销和重做。
- [ ] 拖入任意图形与嵌套表格到合并格时，预览线、落点、归属和导出一致。
- [ ] 无交叠合并、悬空格、孤儿背景文本或丢失内容；不合法结构明确报错。
