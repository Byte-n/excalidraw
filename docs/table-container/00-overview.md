# 表格容器图形：全功能分期总览

## 定位与完成标准

表格是白板上的网格容器，不是电子表格。单元格能容纳画板支持的任意图形，包括另一个表格；双击单元格编辑其背景文本，背景文本始终位于格内普通图形之下。拖入图形的提示属于图形本身，单元格内虚线是对齐辅助线。

本计划覆盖表格从创建到复杂结构编辑、样式、复用、原生格式、协作及移动端的白板工作流。各期实施和验收状态以对应分期文档为准；P05 按调整后的范围完成，语义级协作冲突处理、真实移动设备和屏幕阅读器验收仍列为后续目标。公式、数据排序筛选、数据库字段约束等电子表格功能不属于此图形。各期使用交付时的规范数据结构；本大版本不迁移、不兼容历史元素、文件、库项目、剪贴板数据或旧客户端，入口只接受规范结构。

实施依据：[复合图形数据结构总纲](../composite-shape/design.md)。数据结构、交互规则和验收场景以本计划为准。

## 跨期不变量

1. `type: "table"` 表示语义容器；行、列、单元格使用正式结构字段与稳定 ID，不藏在 `customData` 或 `groupIds` 中。画框和表格单元格使用同一个判别式直接父引用；每个图形至多有一个直接空间父容器，祖先关系沿父链推导，绑定文字沿宿主关系继承。父链必须可校验且无环。
2. 单元格背景文本与普通文本图形分开；前者在所在格内容的最低层，非编辑态不抢占拖入和图形选择。合并时各格背景文案按行列顺序拼入锚点格唯一的背景文本，不丢失原文字；拆分后仅左上角锚点格保留内容，其余恢复的格为空。
3. 拖放预览与提交使用同一目标格判定。结构修改、子树几何、文字模式和绑定更新组成一次用户操作、一次历史记录；取消不改场景。
4. 整体缩放时，支持文字的图形转入固定模式。表格支持四角等比和四边水平/垂直单轴缩放；行高/列宽的局部调整属于另一种操作，不改变普通图形的模式。
5. 行列尺寸和表格外框始终一致；单元格几何由行列推导，全部画布元素的 `x`、`y` 保持场景坐标，归属单独持久化；合并区域不重叠，成员格可追溯；删除、复制、恢复、并发重放后无悬空归属。
6. 普通图形、画框、分组、箭头绑定及规范文件行为与表格共同工作。表格的视觉溢出不等于自动改写归属。
7. 画布渲染、命中、导出和缩略图共用规范几何及层级；明暗主题下可辨识。虚线表示图形对齐，不表示单元格分割。
8. 不符合规范契约的文件、库项目或剪贴板结构须明确反馈，不能静默丢弃内容或把其他语义元素伪装成普通表格。
9. 本大版本不提供历史字段迁移或兼容别名。`frameId` 等旧空间归属字段不属于输入契约；元素、文件、库项目、剪贴板和公开 API 中只接受 `containerRef` 及其当前版本的判别联合。
10. 表格不支持旋转：表格元素不做旋转变换，选中表格的指示器不提供旋转操作入口；框选、套索等选区包含表格时也不展示旋转操作。

## 统一实现与验收门槛

- 元素层提供纯结构命令和校验：创建、插入、删除、排序、尺寸调整、合并、拆分、区域变换和归属解析。画布控制器负责命中、预览和提交；各入口复用同一命令，不在菜单、手势和导入中分别实现规则。
- 每期交付可打开的应用预览、从空白画布开始的操作步骤及已执行的验收结果；未执行的人工验收应明确列为后续目标。P00 样例包含普通画框、Magic Frame 与成员图形；P01 起样例包含普通图形和嵌套表格。无 UI 入口的底层数据能力不算完成。
- 每个语义操作一次撤销、一次重做；保存重开和重复恢复稳定；复制后 ID 与引用正确；取消和无变化不增加历史。
- 文件、库、剪贴板、公开 API、PNG/SVG 等入口均验证相同不变量；持久化字段在交付期进入同一新版本规范。
- 交互至少在明暗主题、缩放画布、选中表格及包含表格的选区、中文输入、长文本、复杂子图形及嵌套场景中检查。P05 已完成 Chrome 桌面及触屏模拟的固定数据集性能采集；真实双端协作与触屏设备验收属于后续目标。
- 对性能和协作有风险的操作，先在临时预览中计算，再原子提交；绝不把拖动中间帧、选区或悬停写入场景与协作数据。

## 最终验收场景

1. 创建普通 3×3 表格，双击不同单元格写背景文本，拖入文本、图形、图片、箭头及嵌套表格；对齐线、选择层级和越格显示正确。
2. 增删、排序、调整行列，合并跨行跨列区域并拆分；原内容与绑定不丢失，拆分后全部归属左上角锚点格，其他恢复的格为空。复制表格与区域后可独立编辑。
3. 既有等比和水平/垂直单轴缩放含长文本与多层嵌套的表格；文字固定模式、几何和撤销正确，文本不撑大单元格。
4. 分别设置表格、行列、格的底色、边框、文字样式、对齐和标题；明暗主题、画布、PNG/SVG 与重新打开的结果一致。
5. 含合并、标题、样式、嵌套及画框父链的表格在原生文件、库、剪贴板和公开 API 中往返，结构与画面无丢失；不合法引用和尺寸得到明确报告。
6. 在 Chrome 桌面及触屏模拟环境检查键盘、结构命中、无障碍代理和固定大表的命中、拖动、缩放、保存与重开。真实双端并发收敛、手机和平板操作及屏幕阅读器验收见 [P05 后续目标](phase-5.md#实施与验收)。
