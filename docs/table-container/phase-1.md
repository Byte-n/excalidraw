# 第一期：表格容器图形

- 状态：设计方案，未实现。
- 定位：白板中的网格容器，不是数据表格或表单。
- 总体完成门槛：[全功能分期总览](00-overview.md)；后续承接：[P02 合并单元格与区域操作](phase-2.md)。
- 依据：[复合图形数据结构总纲](../composite-shape/design.md)；交互参考为已提供的 Lark 白板表格五种状态截图。

## 目标与范围

用户可以在画布上创建表格，把画板支持的图形拖入单元格，在单元格中直接编辑背景文本，调整行列结构和宽高，并整体移动、等比缩放表格。表格本身也可以放入另一个表格的单元格。创建、编辑、复制、撤销重做、保存重开及导出形成完整闭环。

一期包含：普通矩形网格、行列插入/删除/拖动排序/宽高调整、单元格文本、任意画板图形的单元格归属、嵌套表格、整体等比缩放、基本样式和键盘/触屏入口。默认创建 3 行 3 列；初始行高、列宽作为创建预设，可在后续产品验收中调整，不写死为格式约束。

一期不包含：合并单元格、表头语义、公式、排序筛选、批量数据填充、不等比整体拉伸，以及 Lark `table_er`、`table_uml`、`combined_fragment` 的语义导入。现有 Lark `table` 样本含 `merge_info`；带合并单元格的样本在一期不得被静默拆开或伪装为普通网格。

## 核心语义

- 表格是独立的语义元素 `type: "table"`，不作为普通 `composite_shape` 的一种外观。行、列、单元格是表格结构；单元格不是独立的画布元素。
- 单元格可以容纳画板支持的任意图形，包括普通图形、自由绘制、图片、文本、连接线，以及另一个表格。单元格没有“只能放一个组件”的限制。
- 分组、画框、便签、思维导图等多元素图形按自身语义的完整对象进入单元格：直接归属写在可操作根对象上，内部成员通过原有关系继承；拖动单个内部成员仍执行该图形本来的编辑规则，不把语义对象拆成多个格。
- 每个单元格可有一份直接双击编辑的**单元格背景文本**。它与拖入的普通文本图形是两种不同对象；背景文本始终在该单元格内容的最低层，不能阻挡拖入、对齐、选择其他图形。
- 图形的单元格归属是结构关系，不由元素当前是否完全落在单元格边界内推断。允许内容越过边界；默认不裁切、不自动排版，也不因溢出转移到相邻单元格。
- 普通图形仍保持自身的画板属性、绑定关系和编辑能力。表格只管理其位置变换、结构归属和整体操作。

## 数据契约

以下为概念结构，正式字段名以实现期类型评审为准。表格沿用画布元素的 ID、坐标、旋转、样式、排序与协作字段；行列尺寸保存在表格的正式结构字段中，不放进 `customData`。

```ts
type TableDataV1 = Readonly<{
  schemaVersion: 1;
  rows: readonly { id: string; height: number }[];
  columns: readonly { id: string; width: number }[];
  cells: readonly {
    id: string;
    rowId: string;
    columnId: string;
    backgroundColor?: string;
  }[];
}>;

type TableCellRef = Readonly<{
  tableId: string;
  cellId: string;
  role: "content" | "backgroundText";
}>;
```

- 一期每个行列交点恰有一个单元格；行、列、单元格 ID 稳定。排序只改变行列数组顺序，图形仍引用原单元格 ID。插入生成新 ID，删除同时处理该行/列单元格及其内容。
- 表格宽高由列宽/行高之和定义，不能与顶层 `width`、`height` 矛盾。行高、列宽必须为有限正数；加载和协作入口校验重复 ID、缺失交点、悬空引用及容器环。
- 直接放入单元格的画布图形持久化正式的单元格归属引用；不可仅靠矩形包含测试或 `groupIds` 推导，也不可复用 `frameId` 冒充单元格关系。普通图形已有的绑定文字通过 `containerId` 继承宿主归属，不再另存一份可能冲突的单元格引用。嵌套表格只记录直接父单元格，形成无环树。
- 背景文本复用独立的画布 `text` 元素及现有文字编辑能力，以 `role: "backgroundText"` 绑定单元格；每格至多一个，文本框覆盖所属单元格并采用固定宽度。它不是单元格的填充图片，也不是拖入图形的“输入文本”提示。普通文本图形使用 `role: "content"`。
- 渲染次序为单元格底色与网格线、单元格背景文本、单元格内普通图形；普通图形之间沿用场景顺序。表格整体置顶/置底、复制及删除时，其完整子树作为一个连续操作单元处理，保持内部相对层级。
- 复制表格时重新生成表格、行、列、单元格和全部后代图形的 ID，并重映射单元格归属与图形绑定；直接复制某个内容图形时按目标位置决定新归属，不复制整个表格。

## 交互与状态

| 状态 | 触发与视觉反馈 | 主要行为 |
| --- | --- | --- |
| 默认 | 低对比度外框和网格线；无常驻操作点 | 显示内容，不抢占子图形交互 |
| 表格悬停/选中 | 整体蓝色外框；行列边界显示操作点 | 点击边框选表格；拖边框移动整个子树 |
| 单元格悬停 | 仅目标格呈浅蓝底或局部边框 | 空白处可选格；双击编辑背景文本 |
| 图形拖入预览 | 目标格蓝色高亮，拖入图形保持自身真实预览 | 单元格内虚线仅表示图形对齐辅助线；满足吸附阈值时才吸附 |
| 行/列选中 | 对应整行/整列及外侧抓手高亮 | 抓手拖动排序；内容随单元格一起移动 |
| 行高/列宽调整 | 分隔线高亮并显示尺寸指针 | 拖动分隔线调整相邻格位置，不缩放内部图形 |
| 行/列插入预览 | 边界蓝色定位线和加号；悬停提示“插入行/列” | 点击在该边界创建行/列；新格为空 |
| 整体缩放 | 外框与全部子图形同步预览 | 释放后一次性提交几何和文字模式变化 |

交互优先级：可命中的子图形优先于单元格，单元格空白区域优先于表格内部填充，表格外框/专用抓手优先于单元格。背景文本在非编辑态不拦截普通图形的拖入和选择；双击单元格空白或背景文本区域进入背景文本编辑。点击外侧边框选整个表格；再次点击子图形选该图形。`Esc` 退出编辑、拖拽预览或层级选择。

拖入时用图形的放置锚点判定目标格，命中最深层的可见表格。松手后写入归属；拖出表格后解除归属；跨格移动则更新为目标格。预览与提交使用同一判定规则。拖入已有内容的单元格时保留原内容及层级，不替换背景文本。对齐线分别显示格内水平/垂直中心及必要的边缘对齐，不表示分割或新建单元格。

行列的排序抓手、尺寸分隔线与插入加号分开，命中区不小于 24 CSS px，视觉图标可更小。桌面支持鼠标和键盘入口；触屏以长按打开行列操作，避免悬停成为唯一入口。表格、行列、单元格的焦点与辅助技术名称需明确，键盘可到达插入、删除和排序命令。文字编辑和 IME 组合期间不拦截编辑器按键。

## 行列结构操作

- 插入行/列：在预览线所指边界插入，沿用相邻行高/列宽作为初值；新格无内容。插入位置必须与预览位置一致。
- 拖动行/列：改变结构数组顺序，原单元格、背景文本和全部后代图形随行/列移动；移动后保留它们在所属单元格内的相对位置，不改变内部层级。
- 调整行高/列宽：拖动分隔线只改变对应行高或列宽，并平移其后续单元格及内容；被调整行/列内部的普通图形保留相对单元格左上角的位置和自身尺寸，允许溢出。背景文本框跟随单元格宽高调整，字号不变；它不撑大单元格。此操作不是整体缩放，不切换普通图形的文字模式。边界受单元格正的最小尺寸约束。
- 删除行/列：连同该行/列的单元格背景文本和全部后代图形删除；嵌套表格递归处理。操作可一次撤销。至少保留 1 行 1 列；删除最后一行/列应走删除整张表格的明确命令。
- 单元格内图形的独立移动、旋转、编辑、排列顺序仍按画板现有操作工作；不能因为图形跨过网格线就自动改写归属，只有完成一次明确的拖放才重判目标格。

## 整体缩放与文字

一期整表缩放采用**等比缩放**，四角拖动保持宽高比；行高、列宽、单元格坐标和所有后代图形使用同一倍率 `s`。从拖动开始时的快照计算每帧预览，避免连续四舍五入造成漂移。拖动移动表格时只做平移，不改变文字模式。

对所属子树中支持文字的图形，发生实际尺寸变化时统一切换到固定模式，然后缩放图形几何和文字参数：

| 对象 | 一期缩放规则 |
| --- | --- |
| 复合图形及其绑定文本 | `textFitMode` 置为 `fixed`；形状和绑定文本的位置、宽高、字号同倍率变换，文字不再撑大形状 |
| 独立文本图形 | 关闭按内容扩宽的 `autoResize`；文本框位置、宽高、字号同倍率变换，不使单元格增长 |
| 单元格背景文本 | 同样固定文本框并同步缩放；保持格内最低层，不参与拖入命中 |
| 图片、自由绘制、线条、箭头 | 按既有图形几何规则同倍率变换路径点、端点及尺寸；保持绑定关系 |
| 嵌套表格 | 随父表格缩放一次，再递归缩放其行列与后代；不得对子树重复应用倍率 |

并非每种带文字图形都已使用 `textFitMode`。一期须为便签等已有自动测量/撑大机制，以及思维导图等多元素图形提供等价的固定布局适配：缩放时冻结其自动扩容或重新排布，再按同一倍率更新文字和几何；之后编辑内部文字也不能反向撑大所属单元格。对尚无固定模式的类型，先补齐该能力再允许其作为表格子图形，不能静默退回自动尺寸。分组、画框和绑定文字沿语义子树遍历并按 ID 去重。

拖动预览临时采用固定模式排版；模式切换仅在真正提交尺寸变化时持久化。取消拖动或尺寸未变时不修改元素；提交后保留固定模式，避免自动撑大重新改变布局。缩放、模式变化及全部后代几何共用一条撤销记录；撤销恢复原模式、尺寸、字号和归属。

固定模式解决文字反向撑大容器的冲突，但不保证任意小尺寸下文字仍可读。缩放设置正的最小尺寸，约束必须对整棵嵌套表格子树一致生效；达到下限时停止缩小，不允许某些后代单独停止而破坏比例。文本超出固定框时保留原文，由现有文字显示策略处理，不删除、不截断持久化内容，也不自动把图形移到别的格。

整体不等比拉伸留到后续期次：普通文本只有一个字号，无法同时在两个轴上独立缩放并保持原排版。后续若开放侧边拉伸，须先明确文本字号与换行策略。

## 场景集成与边界

- **命中与选择**：表格网格、控制器、单元格空白和子图形分别命中；旋转表格时，命中及对齐基于表格局部坐标。背景文本非编辑态保持“穿透”语义。
- **绑定与跨边界图形**：图形即使视觉上越格，也保持原归属。遍历子树时，绑定文字和其他通过绑定关系关联的元素按 ID 去重，避免重复变换。连线端点若绑定到表格外图形，整体变换后须按现有绑定规则更新连接，不可把外部图形拉入表格或留下悬空端点。
- **保存与导出**：文件、库、剪贴板、公开元素数组、PNG/SVG 导出使用同一正式结构；保存重开后行列次序、背景文本、子图形归属、层级和嵌套关系稳定。未知结构版本明确报错或受控降级，不静默丢格。
- **协作与历史**：插入、删除、排序、拖入、整体缩放按结构操作原子提交；并发编辑以稳定 ID 定位行、列、格，重放后校验引用与无环关系。
- **与画框/分组**：表格归属独立于 `frameId` 和 `groupIds`。相关操作必须处理同时存在的关系，不得通过改变画框或分组关系来模拟表格嵌套。
- **性能**：缩放预览可使用临时变换，但落盘必须得到规范几何；命中索引和渲染缓存按受影响表格子树增量更新，避免每帧扫描整张画布。

## 实施顺序

1. 建立 `table` 元素、稳定行列/单元格 ID、子图形归属引用、结构校验与场景往返；先实现静态网格的渲染、命中与导出。
2. 接入创建入口、表格/单元格层级选择和背景文本编辑；确保普通图形与背景文本的层级及命中正确。
3. 接入图形拖入、跨格/拖出、对齐辅助线与嵌套表格；补齐复制、删除、排序和撤销。
4. 接入行列插入/删除/拖动/宽高调整与整体等比缩放；缩放时统一固定文字模式，并完成绑定关系更新。
5. 补齐键盘、触屏、协作、文件/库/剪贴板和 PNG/SVG 验收。

## 验收清单

- [ ] 默认 3×3 表格在明暗主题下静态网格清楚；悬停、拖入、列拖动、插入列五种状态与参考交互一致，行操作具有对称反馈。
- [ ] 双击空格编辑背景文本；同一格再拖入普通文本及其他图形，背景文本仍在最低层，不阻挡拖入、选中和对齐。
- [ ] 任意支持的画板图形可加入单元格；内容可越格显示，移动、跨格、拖出和嵌套表格的归属明确且稳定。
- [ ] 便签、分组、画框、思维导图和其他多元素图形作为完整语义对象进入单元格；缩放时其文字自动布局不会撑大或拆散表格子树。
- [ ] 插入、删除、拖动及调整行列宽高时，单元格、背景文本、普通图形和嵌套表格按对应规则变化，操作一次撤销完整恢复；局部宽高调整不触发内部图形缩放或文字模式切换。
- [ ] 整体缩小和放大时，所有行列及后代以同一倍率变化；支持文本的图形转为固定模式，文字不撑大单元格；撤销恢复原模式。
- [ ] 最小尺寸、跨表格绑定连线、旋转、深层嵌套、删除含内容行列、复制粘贴、保存重开及 PNG/SVG 导出均无丢失、重复缩放或孤儿引用。
- [ ] 鼠标、键盘、触屏操作可到达核心命令；编辑文本时快捷键不干扰输入法。
- [ ] 对含合并单元格或不支持的 Lark 表格变体明确提示未支持，不将其错误转换为一期普通表格。
