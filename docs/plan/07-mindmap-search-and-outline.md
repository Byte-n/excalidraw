## 用户可见目标

用户可以搜索并定位折叠内容，使用大纲管理节点；画布、大纲和协作端始终反映同一份结构。

## 实施任务

### 搜索与定位

- [ ] 搜索节点绑定文字，覆盖折叠子树，不把同一绑定文本重复呈现为多个结果。
- [ ] 搜索结果显示所属导图和层级路径，区分不同图内的同名节点。
- [ ] 输入查询和切换结果高亮不修改场景结构。
- [ ] 点击隐藏节点结果时展开必要祖先、选中节点并将其移入视口；实际折叠状态修改归入一次历史。
- [ ] 节点被删除、重命名、移动或收到远端变化后更新结果，失效结果不能跳到错误节点。

### 大纲视图与编辑

- [ ] 提供 Mindmap 大纲侧栏，按照图索引和 `order` 展示层级，不依据画布坐标排序。
- [ ] 画布与大纲双向同步选中、标题和折叠状态。
- [ ] 支持大纲内重命名、添加子节点/同级节点、删除、删除子树、折叠、提升及拆图。
- [ ] 支持大纲拖拽挂接和兄弟排序，复用已有目标合法性与提交规则。
- [ ] 大纲不维护第二份可独立修改的树；编辑、历史和协作都走统一命令。
- [ ] 将只读层级呈现与编辑命令解耦，供后续导入和 AI 预览复用，不把预览树写入场景。

## 实现落点

优先扩展 [现有搜索菜单](../../packages/excalidraw/components/SearchMenu.tsx) 及现有侧栏机制；Mindmap 大纲只作为场景元素的派生视图。

## 界面验收

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| P07-01 | 折叠“调研”后搜索“用户访谈” | 仍可找到结果，显示正确导图和路径，输入查询时不自动展开 |
| P07-02 | 点击隐藏结果 | 必要祖先展开，画布定位并选中目标；撤销可恢复折叠修改 |
| P07-03 | 在两张图中创建同名节点后搜索 | 结果可区分，点击分别定位到正确图 |
| P07-04 | 在大纲重命名、添加、删除、提升和拆图 | 画布立即反映相同操作，一次撤销在两处同时恢复 |
| P07-05 | 在大纲拖动分支排序或挂接，再在画布反向调整 | 两种入口的结构与顺序一致，非法目标均被拒绝 |
| P07-06 | 另一端修改或删除当前搜索结果对应节点 | 大纲和结果更新，失效项不跳转到其他节点 |
| P07-07 | 保存重开并重新打开大纲 | 结构来自场景，无大纲专有数据丢失或旧树覆盖新树 |
