## 用户可见目标

用户可以输入主题生成新导图，为指定分支补充子树，或让 AI 重组既有子树；所有结果先预览，由用户确认后才影响画布。

## 实施任务

### 功能入口与服务适配

- [ ] 提供“生成新导图”“为选中节点生成子树”“重排选中子树”三个明确入口。
- [ ] 请求前显示当前目标及发送内容范围，默认只使用本次操作必需的主题或选中子树，不自动上传整幅画布。
- [ ] 通过宿主回调/后端适配接入，核心编辑器不绑定供应商，不在场景数据内存放调用凭据。
- [ ] 明确结构化树输出协议；服务返回文字、层级、顺序及必要的既有节点引用，不由 AI 直接指定画布坐标。
- [ ] 提供加载状态、取消、超时、失败提示和重试，重试不得重复插入结果。

### 生成与重排语义

- [ ] 新图及新子树通过已有身份生成、布局、文本绑定与插入命令构建。
- [ ] 重排保留既有节点 ID、文字、样式和适用通用属性，只调整允许的关系与逻辑顺序，默认不删除已有内容。
- [ ] 校验返回节点引用、唯一根、父子关系、无环、顺序及规模，拒绝越出选中范围的修改。
- [ ] 预览显示生成层级和重排前后的变化范围，用户能判断哪些分支将改变。
- [ ] 确认时重新校验目标及相关源数据是否仍有效；若协作期间目标删除或相关内容已变化，则提示重新生成/预览，不用过期结果覆盖新数据。

### 预览与原子应用

- [ ] 生成中的片段和完成后的待确认结果都只属于本地预览，不进入 Scene、History 或协作。
- [ ] 用户确认后执行一次校验、布局及原子提交，一次撤销完整恢复应用前状态。
- [ ] 取消、失败、无效结果和关闭界面时清理会话，画布不留下半成品。
- [ ] 应用后的内容可继续使用大纲、复制、模板、导出及移动端编辑，不产生 AI 专用的第二种结构模型。

## 界面验收

真实服务验收与异常回归分开记录；异常可用受控测试适配器重现，但不能以固定假结果代替真实生成验收。

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| P11-01 | 输入主题生成三层新导图，先预览再确认 | 预览前画布不变，确认后结构与预览一致且可继续编辑 |
| P11-02 | 选择“方案”要求补充子树 | 请求和应用范围清楚，其他分支保持不变 |
| P11-03 | 对选中子树提出重组要求，先取消，再重新生成并确认 | 取消无变化，确认只修改允许关系，既有节点文字与样式保留 |
| P11-04 | 撤销、重做一次 AI 应用，并保存重开 | 一次撤销完整恢复，重做和保存恢复均保持结构 |
| P11-05 | 测试取消、超时、失败、无效结构及重试 | 无半成品和重复插入，错误可理解，可重新操作 |
| P11-06 | 预览期间另一端删除目标或修改相关子树 | 过期结果被阻止，不能覆盖远端新修改 |
| P11-07 | 一端预览，再确认应用，另一端观察 | 另一端看不到预览，确认后接收完整有效结果 |
| P11-08 | 对 AI 结果执行复制、折叠、导出和大纲编辑 | 与手工创建节点使用同一套行为，无 AI 特殊数据丢失 |
