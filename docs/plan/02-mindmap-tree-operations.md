## 用户可见目标

用户可以通过键盘和菜单整理树结构，折叠分支，安全删除节点，提升层级，并将一级分支拆成独立导图。

## 实施任务

### 导航与折叠

- [ ] 单选且非文字编辑时，`ArrowUp` / `ArrowDown` 按逻辑顺序切换同级，`ArrowLeft` 选父节点，`ArrowRight` 选第一个可见子节点。
- [ ] 导航边界不跳入其他导图；折叠节点的隐藏后代不作为普通导航目标。
- [ ] 节点显示折叠/展开控制点，支持 `Space`；叶子节点不产生无意义折叠修改。
- [ ] 折叠后保留后代、文本和 edge 数据，只重新布局可见节点，清理不再可见的选择状态。
- [ ] 隐藏后代不参与命中与普通框选；展开恢复完整分支。

### 删除与换根

- [ ] `Delete` 或平台对应的删除键删除叶子及其绑定文字、入边。
- [ ] 删除非叶子普通节点时，将其子节点提升到原父节点，在被删节点原位置按原顺序插入。
- [ ] `Shift+Delete` 删除完整子树，包括折叠后代、文字与相关 edge。
- [ ] 删除根节点必须弹出选择：删除整图，或保留子树并从直属子节点中指定新根；取消不改变场景。
- [ ] 保留子树时将其他原一级分支挂到新根下，保持分支内部顺序；不依赖恢复逻辑静默选择新根。
- [ ] 叶子根节点只提供删除整图与取消；删除后选择有效的相邻节点或清除选中。

### 提升与拆图

- [ ] 深层节点执行 `Shift+Tab` 后成为父节点的同级，插在原父节点之后，后代关系保持不变。
- [ ] 一级节点执行 `Shift+Tab` 后连同完整子树拆成新导图：新根的 `parentId`、`order` 置空，整棵子树使用新 `graphId`，移除旧入边。
- [ ] 拆图同时更新原图与新图，保留绑定文本及已有样式；一次撤销恢复原关系。
- [ ] 根节点执行提升时不产生变化。
- [ ] 创建、删除、删除子树、折叠和提升均提供 Mindmap 上下文菜单入口。

使用总览中的基础样例；每个删除或拆图用例单独重新加载样例。
