## 实施任务

### 合并边界与提交

- [x] 在远端数据与本地场景合并后，对完整图执行结构校验、确定性修复与布局，不能仅校验增量元素。
- [x] 同步创建、删除、提升、拆图、重新挂接、排序、文字、样式、折叠、粘贴和整图移动。
- [x] 将本地结构操作作为一次完整场景提交处理，远端不能显示“关系已变但 edge/文字未更新”的持久中间状态。
- [x] 与现有元素版本和合并机制配合，避免重复修复、无意义版本递增与协作回传循环。
- [x] 撤销重做遵守现有协作历史规则，不用旧全图快照覆盖另一端已接受的无关修改。

### 并发与拖拽会话

- [x] 同级同时插入时保持确定顺序，顺序冲突可稳定修复。
- [x] 覆盖同节点并发挂接、潜在环、删除与编辑竞争、多根和缺失 edge 的合并结果。
- [x] 拖拽影子、局部透明度、目标高亮及预览布局不写入待同步数据。
- [x] 拖动期间源或目标被远端删除、结构改变而失效时取消当前会话并提示；松手前重新校验目标。
- [x] 断线重连与场景重载后，各端重新收敛到有效结构。

### 冲突反馈

- [x] 对影响用户操作的结构冲突/修复显示提示，说明相关节点和最终处理结果。
- [x] 提供定位相关节点入口；失效操作不能无提示地产生与预览不符的结果。
- [x] 纯粹的重复消息或幂等修复不持续弹出重复提示。

## 界面验收

两个独立会话 A、B 进入同一协作房间，并使用可控网络延迟或断线步骤重现竞争。

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| P06-01 | A、B 分别编辑不同分支，修改文字、样式、方向和折叠 | 双端正确同步，互不覆盖无关修改 |
| P06-02 | A 拖动分支停留但不松手，随后提交或取消 | B 看不到影子和临时布局；提交后显示完整结果，取消无变化 |
| P06-03 | A、B 同时向相同同级位置新增节点 | 两个节点均保留，最终顺序一致，刷新后不漂移 |
| P06-04 | A、B 并发挂接同一节点，或构造可能成环的两个挂接 | 最终只有一个有效父节点且无环，受影响操作收到反馈 |
| P06-05 | A 拖动时 B 删除目标或源节点 | A 的失效操作取消或被明确阻止，不产生孤儿与幽灵 edge |
| P06-06 | A 拆图或粘贴，B 同时编辑其他分支；再测试本地撤销 | 双端有效收敛，无关远端编辑不被旧快照覆盖 |
| P06-07 | 断线后恢复连接，随后刷新一端 | 图结构、顺序、配置和折叠最终一致，无持续回传闪动 |
| P06-08 | 触发结构冲突提示并点击定位 | 可定位相关节点，提示不无限重复 |
