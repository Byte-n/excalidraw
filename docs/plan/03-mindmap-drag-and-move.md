## 用户可见目标

拖动分支时以所选分支中的第一个根显示半透明副本和目标连接；拖动根节点或混选区域时整图一起移动，不破坏树结构。拖拽副本只代表操作对象，不预演完整子树或最终布局。

## 实施任务

### 拖拽会话与预览

- [x] 超过拖拽阈值后创建本地会话，普通点击仍为选择。
- [x] 仅在渲染层降低被拖分支与连接线的透明度，显示不进入 Scene 的首个分支根副本。
- [x] 指向节点中心时作为最后一个子节点；指向同级插入区域时插入到目标之前或之后。
- [x] 拖动中显示候选目标连接；松手时计算目标关系、顺序和布局。
- [x] 有效目标变化时更新预览，按 animation frame 节流；不让每次 pointermove 触发完整 React 渲染。
- [x] 同图多选提取互不重叠的子树，选中父节点时不重复处理其已选后代，保持分支相对逻辑顺序，并以第一个分支根显示副本。

### 提交、取消与修饰键

- [x] 拒绝自身、后代、跨图和根节点挂接等非法目标，显示无效状态。
- [x] 有效松手时原子更新关系、顺序、edge、布局与绑定文本；清理全部预览。
- [x] `Escape`、空白处松手、`pointercancel`、失去交互上下文或切换工具时取消，不改变数据和历史。
- [x] `Alt/Option` 复制拖动留到 P04 接入，本期不能回落到破坏结构的原生复制拖动。

### 根节点与混选移动

- [x] 根节点拖动为整图平移，不改变 `parentId`、`order` 和 `graphId`。
- [x] 普通图形与任一 Mindmap 节点混选时，选中集合直接扩展到涉及的整棵导图，选区覆盖整图当前可见范围。
- [x] 混选区域和根节点使用一致的整图平移规则；普通图形随选区原生平移。
- [x] 整图平移包括绑定文字、edge 和折叠后代；展开后不能跳回移动前的位置。
- [x] 普通节点的空白处松手是取消，根节点整图平移则可以落在空白位置，两种操作明确区分。

## 界面验收

准备基础导图、第二张独立导图及一个普通矩形。

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| P03-01 | 拖动带后代的“调研”到“方案”中心，先停留再松手 | 先出现首个分支根的半透明副本与目标连接，松手后完整分支挂接到“方案” |
| P03-02 | 将分支拖到兄弟前后插入区域 | 目标连接可见，松手后逻辑顺序与布局一致，一次撤销完整恢复 |
| P03-03 | 多选两个不重叠分支一起挂接；再测试父子同时被选中 | 第一个分支根作为副本视图；分支不重复，不丢后代，相对顺序稳定 |
| P03-04 | 拖向自身、后代、第二张图或空白处 | 非法目标不可提交，普通节点不自由定位 |
| P03-05 | 折叠一个分支后拖动根节点，再展开 | 整图平移，隐藏后代和文字一起移动，结构不变 |
| P03-06 | 混选普通矩形与一个普通 Mindmap 节点后拖动 | 选区直接扩展到整图，矩形与整图一起平移 |
| P03-07 | 先修改一次标题，再开始并取消拖拽，执行撤销 | 撤销的是标题修改，不存在取消拖拽留下的空历史 |
