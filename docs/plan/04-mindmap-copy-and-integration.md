- 期次：P04。
- 状态：待实施。
- 里程碑：完整桌面编辑的复用与兼容闭环。
- 总体约束与完成门槛：[分期总览](00-mindmap-overview.md)。

## 依赖关系

- **前置验收**：[P03 结构拖拽与整图移动](03-mindmap-drag-and-move.md) 须先通过用户界面审查。
- **主要能力依赖**：[P02](02-mindmap-tree-operations.md) 的删除、提升与拆图规则；P03 的子树拖拽会话、预览和整图选择语义。
- **外部依赖**：无新增服务，复用浏览器和应用现有的剪贴板、文件与导出能力。
- **后续承接**：[P05 样式与布局](05-mindmap-style-and-layout.md) 扩展配置复制；P08 导入与 P09 模板复用身份重建和子树插入。

## 用户可见目标

用户可以安全复用整图和子树，使用既有复制、链接、锁定与导出功能，并在明确解除结构后转换为普通图形。

## 实施任务

### 复制、剪切与粘贴

- [ ] 按语义收集整图或子树的全部节点、绑定文本和内部 edge，包括折叠后代；不复制子树原父节点的入边关系。
- [ ] 整图或子树粘贴为新图时生成新节点 ID 和新 `graphId`，修复所有内部引用。
- [ ] 提供“粘贴为当前节点的子节点”和“粘贴为新导图”两个明确入口。
- [ ] 粘贴为子节点时使用目标图的 `graphId`，重新分配 ID 与同级顺序；允许通过明确的粘贴操作跨图复用。
- [ ] 接入原生复制、剪切、粘贴和重复复制快捷键；文字编辑期间保留文字剪贴板行为。
- [ ] 剪切在剪贴板写入成功后再删除完整所选子树，防止写入失败时丢失内容；每次场景修改保持原子历史。
- [ ] 接入 `Alt/Option` 子树复制拖拽，复用 P03 预览；取消不生成正式副本。

### 原生操作边界

- [ ] 适配节点链接、锁定与解锁；检查操作实际影响的元素，不能通过移动父节点或混选绕过锁定。
- [ ] 节点转普通图形前解除结构关系；普通节点的剩余子节点按 P02 规则提升。
- [ ] 根节点转换涉及剩余分支时明确提示处理范围；支持整图转换，内部 edge 转为普通线。
- [ ] 转换保留对应文字、样式和可保留的通用属性，清理不再适用的 Mindmap 关系字段。
- [ ] 继续阻止 edge 独立端点编辑，以及绕过自动布局的节点自由旋转、缩放等原生变换。
- [ ] 对原生菜单、快捷键和重复复制入口使用一致的守卫与语义，避免只有专用按钮正确。

### 导出与往返

- [ ] PNG、SVG 导出当前可见布局，正确处理节点、文字、edge 和选中范围。
- [ ] JSON 保存完整子树、折叠状态及正式字段，重新打开后仍可继续编辑。
- [ ] 复制后修改副本不得影响原图；普通图形复制及宿主扩展字段保持兼容。

## 实现落点

复用 [元素复制流程](../../packages/element/src/duplicate.ts)、[应用复制集成](../../packages/excalidraw/components/App.duplicate.ts) 和现有导出入口。不能仅在专用菜单中另建复制逻辑而遗漏通用快捷键。

## 界面验收

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| P04-01 | 复制折叠的“调研”，分别粘贴到原图、另一张图和空白处 | 三种结果均完整，展开后文字和内部连接线不缺失 |
| P04-02 | 修改粘贴副本，再保存重开 | 原图不变，副本没有与原图重新合并 |
| P04-03 | 剪切一个分支，再粘贴；分别撤销粘贴和剪切 | 每次修改可独立完整撤销，原图不残留孤儿节点 |
| P04-04 | 使用重复复制及 `Alt/Option` 拖拽复制；另做一次取消 | 正式副本独立，取消不留下节点、edge 或空历史 |
| P04-05 | 给节点添加链接并锁定，尝试直接及通过父节点间接修改 | 链接可用，锁定不会被结构操作或混选绕过 |
| P04-06 | 转换一个普通节点，再转换一份整图副本 | 剩余结构有效，转换结果可作为普通图形编辑，原图不受影响 |
| P04-07 | 折叠一个分支后导出 PNG、SVG | 只包含当前可见内容，没有隐藏文字、幽灵 edge 或错误边界 |
| P04-08 | 同一场景保存 JSON 并重开、展开分支 | 完整子树、链接与锁定信息按其持久化语义保留 |
