## 用户可见目标

用户不依赖实体键盘即可在手机和平板上完成核心 Mindmap 编辑；中大型导图的拖拽、折叠、搜索和编辑保持可用。

## 实施任务

### 移动界面与手势

- [ ] 在手机和平板提供工具入口，以及创建、编辑、添加、折叠和上下文操作控件。
- [ ] 提供提升、拆图、删除节点、删除子树等无键盘操作方式，不依赖桌面 hover 才能发现功能。
- [ ] 支持触摸子树拖拽、目标提示、同级排序、取消和根节点整图移动。
- [ ] 明确区分节点操作、画布平移与双指缩放；进入双指手势或收到 `pointercancel` 时不能误提交旧拖拽目标。
- [ ] 多方向布局下的控制点、命中范围和预览适合触屏操作。
- [ ] 处理软键盘遮挡、输入焦点、屏幕旋转与工具切换；文字输入不触发结构快捷操作。
- [ ] 复用 owner document/window 与现有设备布局机制，不引入依赖全局窗口的专用分支。

### 大图计算与渲染

- [ ] 优化图索引与目标查找的复用、受影响图的布局、动画帧节流和渲染更新。
- [ ] 不为每次 pointermove 重建完整 React 界面或无关导图的结构。
- [ ] 保持深树遍历不依赖递归调用栈，折叠数据完整保留。
- [ ] 提供 500 个可见节点的中型样例，以及 2000 个总节点的宽树、深树和折叠样例。
- [ ] 进入本期时固定设备、浏览器、窗口、缩放和样例，记录优化前后同条件数据。
- [ ] 桌面 500 可见节点的持续拖拽预览以至少 30 FPS 为目标；2000 总节点样例可正常打开、折叠、搜索与编辑，无崩溃和持续无响应。交付报告列明实测结果，未达到的目标不能隐去。
