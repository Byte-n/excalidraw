## 用户可见目标

用户可以保存并重复插入自己的分支模板，应用节点样式和整图主题，并在确认前预览外观变化。

## 实施任务

### 节点与子树模板

- [ ] 提供内置节点样式模板与可辨认的缩略展示。
- [ ] 将选中子树保存为命名模板，包含完整结构、文字、样式、折叠数据和必要布局配置。
- [ ] 复用既有本地持久化或素材库机制，刷新后仍能访问保存的模板。
- [ ] 模板面板可以插入到选中节点下或作为新导图，插入时重新生成节点、文本、edge 身份和适用的 `graphId`。
- [ ] 插入后与模板及原图完全独立，不保持会被共同修改的元素引用。
- [ ] 模板插入遵守目标图布局规则，复用 P04、P05 的配置继承和原子提交。

### 主题预览与应用

- [ ] 提供内置导图主题，覆盖节点和 edge 的协调样式。
- [ ] 明确作用范围：整图或选中子树；节点样式模板的应用范围同样可见。
- [ ] 预览使用独立渲染结果，不提前修改正式元素、历史和协作状态。
- [ ] 确认后仅应用样式及必要尺寸布局，不改变文字、父子关系或同级顺序。
- [ ] 取消恢复原外观；确认应用可一次撤销；预览期间选择或目标失效时清理预览。

## 界面验收

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| P09-01 | 将含折叠后代的复杂分支保存为命名模板，刷新应用 | 模板仍可找到，预览包含正确结构信息 |
| P09-02 | 在另一张图中插入模板，再作为新图插入 | 结构、文字、样式完整，目标图与新图配置符合既有规则 |
| P09-03 | 修改一个插入结果，再次插入同一模板 | 原图、已保存模板与另一份副本不受影响 |
| P09-04 | 对节点应用样式模板，对子树和整图分别预览主题 | 范围明确，只有目标范围发生预览变化 |
| P09-05 | 取消一次主题预览，再确认另一主题并撤销 | 取消完全恢复；确认可一次撤销，不修改结构与文字 |
| P09-06 | 在协作中预览并应用主题、插入模板 | 另一端看不到本地预览，确认后收到完整结果 |
| P09-07 | 保存应用主题后的场景并重开 | 外观保留，分支关系和折叠数据不丢失 |

## 自动化与回归

- [ ] 模板持久化、完整折叠子树收集、重复插入身份唯一性与引用隔离测试。
- [ ] 模板作为新图和子树插入的配置继承、目标失效和原子历史测试。
- [ ] 主题作用范围、取消清理、样式尺寸变化与结构不变测试。
- [ ] 验证预览不进入协作载荷，应用和模板插入可正确同步。
- [ ] 回归复制、导入、样式面板和保存恢复。

## 本期不包含

不新增云端模板市场或跨账号模板服务；模板的本地可复用与刷新保留是本期范围。自定义远端共享属于另行确认的扩展。
