## 用户可见目标

用户可以把文本或大纲文件转为新图或已有节点的子树，先检查预览再确认，并把现有导图导出为三种层级文本格式。

## 实施任务

### 格式解析与错误反馈

- [ ] 提供文件导入和粘贴文本入口，支持 Markdown、Outline、OPML。
- [ ] Markdown 支持标题与嵌套列表的层级表达；Outline 支持缩进层级；OPML 支持树结构。
- [ ] 将各格式解析为统一的临时树描述，再校验层级、文字、顺序和规模，不直接把解析过程写入 Scene。
- [ ] 明确提示不支持或不能无损表达的内容，不能静默丢弃后再宣称完整导入。
- [ ] 对格式错误、非法层级和规模超限展示可定位的错误信息。
- [ ] 导入内容按文本处理，不执行 HTML、脚本或外部资源解析；OPML 不解析外部实体。

### 预览与导入提交

- [ ] 解析后显示只读层级预览、节点数量及目标位置。
- [ ] 提供“作为新导图”和“追加到选中节点”两种模式，明确展示追加范围。
- [ ] 确认时使用统一插入命令生成新身份、文本和 edge，执行布局并一次提交。
- [ ] 预览期间目标被删除或改变时重新校验，失效目标不能提交。
- [ ] 取消、读取失败、解析失败和确认前的协作变化不产生半成品或空历史。

### 文本导出与往返

- [ ] 按逻辑顺序导出整图或选中子树，包含完整结构中的折叠后代。
- [ ] 三种文本格式保证支持范围内的文字、层级与顺序往返。
- [ ] 界面说明样式、布局配置、精确坐标和折叠状态不作为文本格式的完整保真承诺，完整场景继续使用 JSON。
- [ ] PNG/SVG 当前可见状态导出继续沿用 P04，不受文本导出完整层级规则影响。

## 界面验收

提供每种格式的有效三层样例、异常样例及带折叠状态的导图样例。

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| P08-01 | 分别导入 Markdown、Outline、OPML 三层样例 | 先出现层级和节点数量预览，确认后结果一致 |
| P08-02 | 将同一份输入追加到“方案”下，再作为新图导入 | 目标和顺序正确，其他分支不变，新图可独立编辑 |
| P08-03 | 从折叠导图导出三种格式，再重新导入 | 折叠后代没有丢失，文字、层级及兄弟顺序保持 |
| P08-04 | 导入错误文件、非法缩进或超限输入 | 明确提示问题，场景保持原样 |
| P08-05 | 完成预览后取消，再执行一次正常导入并撤销 | 取消不改变场景；一次撤销完整移除该次导入 |
| P08-06 | 预览追加位置时由另一端删除目标，再确认 | 提示目标失效，不生成孤儿节点 |
| P08-07 | 导入后在另一端查看，保存重开并用大纲检查 | 协作、画布、大纲与持久化结果一致 |
