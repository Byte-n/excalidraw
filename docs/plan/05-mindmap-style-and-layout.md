## 用户可见目标

用户能在样式面板中调整节点与连接线外观，切换四种布局方向，并在复制、换根、拆图和重开文件后保留配置。

## 实施任务

### 节点与连接线样式

- [ ] 提供矩形、椭圆、菱形、胶囊四种节点形状。
- [ ] 接入填充色、边框色、边框粗细、字体、字号、文字对齐、圆角和透明度等适用样式。
- [ ] 字体、字号、形状等影响文本空间的修改重新测量尺寸并布局；纯颜色修改不改变结构。
- [ ] 提供 edge 颜色、粗细、线型及 `orthogonal` / `curved` 路由。
- [ ] 通过节点的入边设置与整图连接线设置暴露样式，不开放 edge 端点自由编辑。
- [ ] 重新布局及 edge 修复保留用户样式，不重复重置为默认外观。

### 多方向布局与交互

- [ ] 支持左到右、右到左、上到下、下到上，默认延续左到右。
- [ ] 提供层级间距和兄弟间距设置；默认延续已有的 80 和 24，拒绝非法数值。
- [ ] 布局保持根节点锚点，按逻辑 `order` 安排兄弟及子树，按形状边界计算连接线连接位置。
- [ ] 四种方向下同步调整添加控制点、折叠控制点、同级插入区域和拖拽预览。
- [ ] 键盘仍按“上下同级、左父、右子”的逻辑语义导航，不随视觉方向改义。
- [ ] 提供“重新布局”命令；普通结构操作的自动布局仍归属于原操作。

### 配置持久化与兼容

- [ ] 在根节点的正式类型字段中保存图级方向、间距及必要默认样式，不使用 `customData` 或仅保存在本地 AppState。
- [ ] 旧文件缺省字段恢复为现有布局默认值，重复恢复结果稳定。
- [ ] 换根、拆图、复制与粘贴为新图时正确继承配置；粘贴到现有图后遵守目标图布局配置。
- [ ] 保存、导出、撤销重做覆盖全部新增设置。

## 界面验收

使用含不同尺寸、四种节点形状和折叠分支的多层导图，每种方向均执行一次编辑与挂接。

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| P05-01 | 依次切换四种方向 | 根锚点稳定，兄弟顺序可辨，子树不重叠，连接线方向正确 |
| P05-02 | 调整字体、字号、形状与长文本 | 文本容纳正确，节点尺寸与连接线同步更新 |
| P05-03 | 分别修改节点入边与整图连接线样式，再重新布局 | 作用范围明确，路由正确，样式不被重置 |
| P05-04 | 调整两种间距并撤销、重做 | 布局随设置变化，一个设置操作可以完整撤销 |
| P05-05 | 在四种方向下添加、折叠、拖拽挂接及同级排序 | 控制点和插入指示器与实际结果一致 |
| P05-06 | 复制整图、拆分一级分支、删除根并指定新根 | 各路径正确继承或应用布局配置 |
| P05-07 | 保存重开新配置场景，再打开旧版默认场景 | 新设置保留，旧场景兼容，PNG/SVG 与可见状态一致 |
| P05-08 | 在非左到右布局中使用方向键 | 导航仍遵循父子/同级逻辑，不意外变成坐标移动 |
